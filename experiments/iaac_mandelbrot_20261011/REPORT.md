# 접힘 입력과 Mandelbulb의 분리 비교

**판단: 부분 채택.** 프랙탈 장을 이용한 실제 변형은 구현됐고, 입력 매스의 접힘 관계가 결과를 크게 바꾼다. 그러나 현재 필드의 최근접 이동만으로 IAAC의 깊고 유기적인 컵형 접힘을 재현했다고 볼 수 없다. 지금 우선할 것은 방향별로 다른 접힘과 이웃 구간의 겹침이다.

**용어 정정:** 여기서 ‘접힘 입력’이라고 부른 D 계열은 접힘선 기반 folding 알고리즘이 아니라, 방향별 단면 폭·깊이와 축방향 정점 위치를 바꾼 직접 모델링 매스다. 일부 면은 되돌아가지만 crease와 이웃 면의 꺾임·굽힘을 함께 계산하지 않았다. CC의 좌표 평균화가 넓은 팽창을 둥글게 만들어 쿠션 같은 인상에 기여한다고 판단한다. 이를 실제 origami 또는 접힘선 기반 생성의 성과로 설명하면 부정확하다.

사용자가 긍정적으로 평가한 `input_field/DIRECTIONAL_FIELD/G02_CC`는 **유망한 조형 비교 기준**으로 별도 보존한다. 그 안의 큰 흐름과 표면 발달을 유지할 가치는 있다. 현재 단면/축방향 변형의 강도만 높이는 후속 분기는 중단하고, 접힘선을 따라 면 관계가 실제로 달라지는 입력 방식이 필요한지 검토한다.

사용자가 제시한 형상은 [공개 도판](https://www.iaacblog.com/wp-content/uploads/2020/12/pres125.png)의 **LOOP 1 + Catmull–Clark**이다. G0 입력 자체는 확인되지 않았다. 입력 매스와 Mandelbrot 장이 별도로 준비됐다는 가설은 구현 구조로는 타당하지만, IAAC의 실제 작업 이력으로 확정하지 않는다. 전체 출처와 미확인 부분은 [SOURCES.md](SOURCES.md)에 있다.

## 실제 비교에서 확인한 것

동일한 25×32 토폴로지로 원통/접힌 입력 × 필드 OFF/ON의 네 경우를 만들었다. 모두 두 번의 bilinear 분할 후 동일한 한 번의 CC를 적용했다. 각 경우의 입력·G1·G2·CC 메시를 보존했다.

| 비교 | 얻은 것 | 남은 문제 |
|---|---|---|
| 원통 + 필드 | 두 구간의 팽창과 표면 발달 | 원통 목과 팽창부가 따로 읽힘. 반복만 늘리면 잘게 구겨짐 |
| 방향별 접힘 입력, 필드 OFF | 정면·측면의 팽창 높이가 어긋나고 같은 표면에서 이어짐 | 넓은 면과 곧은 중심 골, 깊은 컵형 되접힘 부족 |
| 같은 접힘 입력 + 같은 필드 | 큰 접힘의 윤곽이 남은 채 여러 영역이 발달 | 장이 닿는 영역에 잔주름이 몰림. 접힘 사이 결합의 개선은 제한적 |

실제 비교 이미지: `review/input_field_front.png`, `input_field_oblique.png`, `input_field_side.png`. 중간 단계는 `input_field_stages.png`. 모든 뷰의 카메라·조명·재질은 동일하다.

## 짧은 접힘 방식 시험

| 후보 | 독립 평가 |
|---|---|
| D02 INTERLEAVED | **기준으로 보존.** 서로 다른 방향의 능선과 되접힘이 높이 방향으로 겹친다. 현재 가장 유용한 단순 입력 |
| D04 DEEP RETURN | 되접힘 강도를 높여 마디의 걸림과 끝단을 강화했다. 핀/화살촉 인상과 자기교차가 생겼으며 컵형 수렴은 충분히 생기지 않았다. 공격적인 비교안으로 보존 |
| D05 CURVED PATH | 접힘의 재료 좌표와 공간 방향을 분리해 일부 골과 능선을 실제로 이동시켰다. 측면 방향 변화는 생겼지만 효과가 작고 큰 면이 남는다. 보조 가능성으로 보존 |
| D03 CREASE DRIFT | **실패.** 처음에는 각도에 연결된 항을 모두 바꿔 연속 표면의 재매개화만 일으켰다. 실질적인 접힘 이동으로 평가하지 않는다. 메시·이미지와 실패 사유를 보존 |
| F01–F06 | 네 방향 동일 접힘을 강화해도 참조의 방향 차이를 설명하지 못했다. 추가 발전 중단 |

위 접힘 입력에는 실제 CC만 적용했다. 이 자체를 프랙탈 생성이나 물리적 origami라고 부르지 않는다. D02/D04/D05에는 동일한 프랙탈 장도 따로 적용해 G2까지 비교했다. 원형 비교는 `review/fold_modes_geometry_*.png`, 필드 적용 비교는 `fold_modes_field_*.png`다. 두 행군의 분할 순서는 다르므로 필드 자체의 효과 판단에는 앞의 2×2 비교를 사용한다.

## 핵심 검사

검사 대상의 삼각 메시와 렌더 메시가 동일하다. 좌우 반사 정점 오차는 아래 모든 경우 **0**, 반사된 삼각형 연결도 대응한다. 모두 **한 연결체·폐합·경계선 0·비다양체 에지 0**이다.

| 실제 저장 메시 | 자기교차 |
|---|---|
| D02 CC2 | CGAL 탐지 없음 |
| D04 CC2 | **확인됨** |
| D05 CC2 | CGAL 탐지 없음 |
| 2×2의 원통/접힌 입력, 필드 OFF, G2 CC | CGAL 탐지 없음 |
| 2×2의 원통/접힌 입력, 필드 ON, G2 CC | **둘 다 확인됨** |
| D04/D05 필드 ON, G2 CC | **둘 다 확인됨** |

CGAL `detect_only=True, first_only=True` 검사다. 교차가 검출된 쌍은 증거이며 전체 교차 개수가 아니다. 다른 중간 메시 및 36개 전체의 교차 검사는 반복하지 않았다. **두께·구조 성능·제작 가능성은 전부 미검증**이다. 폐합 상태가 교차 없는 고체를 뜻하지 않는다.

## 계속할 가치

사용자가 말한 ‘침범’은 반드시 면의 자기교차를 뜻하지 않는다. 서로 다른 방향의 접힘 영향 범위가 겹치고 한쪽 팽창이 이웃 골/되접힘과 이어지는 관계가 유효한 단서다. 현재는 그 관계가 일부 나타났지만 깊은 골과 돌아드는 면의 구성은 부족하다. 강도만 계속 높이면 해결된다고 판단하지 않는다.

Origami의 **곡선 접힘과 접힘 간 결합**은 관련 있는 다음 참고 원리다. 실제 공개 시뮬레이터와 곡선 접힘용 구현을 확인했으나 설치·통합하거나 종이의 비신축성 제약을 적용하지 않았다. 현재 엔진으로 형상 비교는 가능하다. 실제 접힘선 도안과 면의 휘어짐을 함께 풀어야 할 때 해당 구현을 사용할 가치가 있다. IAAC가 origami를 사용했다는 증거는 없다.

전체 36개 필드 레시피와 이전 후보는 E 드라이브에 보존했다. V16의 100% 최근접 투영은 면적 퇴화 실패로 따로 저장했다. 이번 접힘 비교는 여기까지로 제한했다. 입력의 방향별 골, 되접힘 깊이, 이웃 구간의 연결 폭이 다음 조형 조절의 우선 변수다.
