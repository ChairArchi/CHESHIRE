# Fold-band / birth-role growth comparison

Bounded geometry experiment on preserved folded columns. Large outputs:
`E:/CHESHIRE_DATA/fold_band_growth_20261011`. Compact review:
`docs/fold_band_growth_20261011/REPORT.md`.

No physical origami solver, separate XYZ smoothing, texture synthesis or
original IAAC executable-code claim. Weighted DS and Task36 stencils do combine
coordinates as part of placement; this differs from a separate smoothing pass.

## Comparisons

- `BAND_COUPLED`, `BAND_REGIONAL`: same SPAN_R2 sampled input, finite n4 field,
  fraction .18, refined outside targets, field budgets .35/.28/.22 and existing
  authored return schedule as SPAN_RETURN_FINE. Only the NEW field vector is
  coupled on material guides; regional also restricts its activation.
- `ROLE_VERTEX_FACE`, `ROLE_EDGE_FACE`: SPAN_COARSE input, no Mandelbulb field
  or added PCHIP return. Bilinear splits followed by separate V/E/F offsets.
- `ROLE_SPARSE_VERTEX_FACE`: same analytic input at Q400; same support-scaled
  coefficients; stopped after G1 because sampling alone did not create new
  relationships. It is a resolution ablation, not new input design.
- `ROLE_ABSOLUTE`: same sparse input, placement scale .3 model units instead
  of local support radius; same .32/0/-.55 coefficients, guide and decay.
  G1-G3 actual meshes/renders retained. The term absolute refers to placement
  scale, not fixed final offset: guide and generation decay still multiply it.
- `FIELD_SEED`: same sparse input, G1-G3 bilinear splits + finite n4
  nearest-outside passes, fraction .55, budgets .35/.28/.22; no authored return
  or guide coupling. Its G1 is the actual input of the sequential curve tests.
- `CURVE_CIRCLE`, `CURVE_SWEEP`: same actual FIELD_SEED input, .3 placement scale
  and V/F coefficients, exact distance to fixed physical polyline attractors.
  Circle versus height-spanning sweep is the controlled comparison. Two further
  subdivision/offset stages give THREE total growth passes (one field + two
  roles), not three repeated field passes. The field uses 18 internal escape
  iterations; that number is a different count.
- `FULL_LOOP`: ONE split + circle-activated birth-role placement + finite field
  in EACH of three growth cycles. True integrated recurrence, not six cycles.
  G2 is clearer; G3 adds roughness without new macro organization.
- `MASS_CURVE`: one common normal response, stopped at G1 after puffing the
  body and weakening the original deep returns. No G2 was generated.
- `RADIAL_SPARSE`: preserved signed radial inside/outside operator on the same
  sparse input and n4 classifier. Stopped G2 for sawtooth/thorn bands. The .22
  radial response is not an equal-amplitude ablation of nearest attraction .55.
- `QUAD_NEAREST`, `TRI_NEAREST`: same actual initial surface, physical counts
  and coarse outside-target field. Triangle render fans become next controls;
  quad render fans do not. Stopped G2; topology alone gave weak formal gains.
- `DUAL_FIELD_LOOP`: existing weighted Doo-Sabin corner placement plus the
  field every cycle. Positive STANDARD lineage carries chart independently of
  signed geometry. True face/edge/vertex families pass forward. G2 is the
  clearer geometric-cell comparison; G3 crust obscures scale contrast. The two
  8-gons use the existing STANDARD/zero-extrusion fallback at G2/G3. This is not
  evidence IAAC used DS.
- `FIELD_STAGED`: same sparse field-only loop, but internal escape iterations
  4/8/18 rather than 18/18/18. All THREE growth cycles retained. Lower finite
  iterations change occupancy and outside targets, not a pure frequency filter.
  This reuses an existing CHESHIRE staging hypothesis, not a recovered IAAC rule.
- `ANCESTRY_LOOP`: existing Task36/reference weighted inherited-diagonal
  placement + finite field every cycle. Standard CC averaging gain is zero;
  weighted stencils still combine XYZ. G2/G3 deeper cross-ledges coexist with
  large recesses. Initial V/E/F eligibility is zero; actual descendants enable
  ancestry in G2/G3. This is class lineage, not tagged crease-feature memory.
  Old V are held during Task36, then eligible points move in the field. Existing
  Task36 plane-only terminal constraints remain explicit.
- `ANCESTRY_STAGED`: same ancestry recipe with the 4/8/18 field hypothesis.
- `ANCESTRY_RETURN`: same ancestry recipe; adds one existing explicitly authored
  radial/axial PCHIP waist return ONLY after the G3 field. It is a CHESHIRE
  design combination, not a fold spontaneously generated by Mandelbrot.

Quad refinement creates `[old V, new E, new F]`. Render-only fan centres are
added afterwards and never become next-generation control points.

Only explicit `review_growth.py --validate NAME/Gxx` runs core checks. The
selected stages already have saved checks; do not repeat them without
changed geometry or an unresolved concern. Confirmed intersections remain
recorded, without collision repair or fabrication claims.

Current recommendation: `ANCESTRY_STAGED/G03` and `ANCESTRY_LOOP/G03` as co-leads.
`DUAL_FIELD_LOOP/G02` is an independent geometric-cell comparison; the authored
waist return is a recorded cuff/belt integration failure. G3 checks of both
ancestry leads and G2 DS confirm single closed symmetric surfaces AND actual
self-intersections. Neither topology closure nor the renders certify fabrication.

## Source distinction

IAAC's original Mesh Subdivision page separates Mandelbrot-derived columns,
different subdivisions and extra attractor curves. Related DragonSkin
diagrams distinguish existing-vertex and face-centre normal offsets.
`research_notes.md` records facts, inference and unknowns. Our guide coupling,
coefficients and generation schedule are declared CHESHIRE choices. Public
images do not establish identical source code or a single controlled +1/+2
progression. See source links in that note.
