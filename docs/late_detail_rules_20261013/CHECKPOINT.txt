결론

두 입력에서 같은 규칙으로 작은 표면 형상이 발생했다. NORMAL_ONLY와 COMBINED는
근접 시각 변화가 명확하며, 같은 폴리곤 수에서 비중립 규칙의 효과를 확인했다.
다만 규칙적인 셀·비늘과 작은 사선 조각이 우세하고, 부모 골에서 더 작은 골로 이어지는
접힘 위계는 아직 미완성이다. 디테일 밀도 개선과 최종 조형 채택을 구별한다.
전체 조형 채택은 보류한다. 기존 승인 기둥 RELAXED_G06과 게이트 JOINED는 보존했다.

실제 구현

보존 SIDEWALL_FAN G4에서 Eq4 위치 혼합 두 계수 묶음과 법선 돌출 세 계수 묶음을
OFF/ON으로 분리했다. NEUTRAL / EQ4_ONLY / NORMAL_ONLY / COMBINED 각 두 입력이다.
기존 reference-coupled CC와 LOCAL_INCIDENT_SCALE을 재사용했다.
w3/w4=1.8/.6은 무차원 위치 혼합값이며 local scale을 곱하지 않는다.
wf/we/wp=.8/−.2/.4에만 현재 local scale과 해당 normal을 곱한다.
metadata.weights의 0은 기본값이고 실제 활성 제어는 evidence의 resolved_* 배열이다.
과거 legacy 실험의 고정 world length나 참고 저자의 수치를 복구한 것이 아니다.

G3 실제 root/child 소유권을 G4 parent_face로 전파했다.
각 G4의 109,408 quad 중 직접 지원은 10,368개(약9.48%)다.
실제 V/E/F 출처의 Eq4 eligible은 109,408개, fallback은 0이다.
incident support를 평균한 edge/vertex 제어와 coupled 경계 영향도 함께 기록했다.
연결 동일성은 각 입력 내부 네 조건에 해당하며 SPAN과 COUNTER의 ordered ID를 같다고 하지 않는다.
개별 다섯 계수 효과·새 분기 생성·전체 표면 활성화를 시험한 것은 아니다.

시각 결과

EQ4_ONLY는 경계와 벽의 계단형 면·띠를 강화한다.
NORMAL_ONLY는 곡면을 따라 반복되는 촘촘한 셀·비늘형 돌기를 만든다.
COMBINED는 보다 사선적인 작은 날·조각과 불규칙한 표면 조직을 만든다.
두 입력 모두 같은 모드별 경향이 관찰되지만 옆 날을 미세 반복층으로 덮는 인상이 남는다.
새 작은 골의 진행과 부모→중간→미세 접힘의 연속 위계는 충분히 읽히지 않는다.
시각 변화와 밀도 개선은 확인됐고, 목표 조형과의 차이는 남는다.
32개 실제 원본과 8개 비교 보드를 판독한 상세 기록은 VISUAL_REVIEW.txt에 있다.

비교할 근거가 생겼다. 계수 강도나 조명만 바꾸어 목표 위계를 확보했다고 설명하지 않는다.
