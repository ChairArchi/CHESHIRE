CHESHIRE — G6 짧은 파장과 깊이 대조 후보
2026-10-13 / 미실행 제안

선택 근거

이번 G5는 작은 셀을 줄였지만 root 폭 약2주기의 방향장으로는 작은 child 면이
넓게 휘는 효과가 우세했다. 연속성을 높이는 것만으로 미세 위계가 생기지는 않았다.
일단 이 기술을 폐기하거나 G7까지 반복하기 전에 파장과 깊이를 구분할 수 있다.

공통 입력과 새 평가

이번 trial01의 실제 DIRECTIONAL G5를 양 입력의 공통 부모로 보존한다.
G3의 보존 root PCA/반경을 유지하고, actual G5 parent_face와 G4 parent_face를 합성하여
G3 소유권·역할·반사 signs를 실제 계보로 전파한다.
G5의 실제 XYZ·normal·incident scale·classes·degree는 다시 평가해야 한다.
동일 소유권 support를 유지하면 기존 SOURCE 면의 공백을 채우는 시험은 아니다.
활성 부위에서의 골과 깊이를 미활성 큰 면의 공백과 구별한다.
기존 G4 전용 연산자에 G5를 G4로 위장해 넣지 않는다.
새 코드·recipe·출력을 별도 보존하고 이번 여섯 상태와 생성 코드 SHA를 수정하지 않는다.

최소 대조 후보

파장 λ=.35R, normal amplitude A=.8 /1.6, 각 SPAN/COUNTER, 총 네 신규 G6 상태.
보존 root minor extent 기준 예상 주기는 SPAN4.4113 /COUNTER3.9200이다.
이는 보존 반경과 extent에서 계산한 예상치이며 실제 생성 성과가 아니다.
A=.8은 subdivision 이후 local scale 감소와 절대 깊이 약화의 가능성을 포함한다.
A=1.6은 감소한 scale에 대해 깊이를 유지하려는 가설이다.
실제 G5 scale이 정확히 G4의 절반이라고 가정하지 않고 support 안의 분포를 측정한다.
파장 단축과 amplitude 변경을 구별하며, 이 네 조건이 완전한 factorial이라고 표현하지 않는다.
CC 정리 효과 자체를 분리할 필요가 있으면 중립 G6 두 상태를 별도 대조로 추가할 수 있다.

진행 기준

먼저 실제 incoming G5에서 phase 이웃 차이와 current scale을 확인한다.
원본과 같은 카메라·재질에서 연속 골의 길이·깊이와 작은 분화를 판독한다.
실제 저장 native의 연결성과 X/Y 대칭은 별도로 검증한다.
단순히 촘촘한 약한 물결·작은 림만 늘면 fine-detail 진전으로 채택하지 않는다.
실패 시 G7을 자동 실행하지 않고 현재 child의 폭·법선 관계와 topology 분화로 돌아간다.

이번 checkpoint에는 위 실험을 실행한 메시·렌더·검증 결과가 없다.
