CHESHIRE · CENTRAL_SPINDLE · 다른 초기 매스의 동일 후속 규칙 적용
2026-10-13 · Asia/Seoul

결과와 판단
기존 SPAN과 크게 다른 초기 매스를 사용하여 G0부터 실제 subdivision G7까지 생성하였다. 기존의 상하 두 팽창부와 좁은 허리를, 중앙의 큰 팽창부와 양끝의 긴 테이퍼로 바꾸었다. 이 실루엣 차이는 최종 G7에도 남는다. 긴 S자 골, 겹친 잎 가장자리, 말린 어깨와 팬 등 기존의 유동적인 조형 언어도 관찰된다.
사용자는 이번 결과의 미적 완성도를 낮게 평가하였으며, 공식의 확보는 확인하였다고 응답하였다. 이번 결과를 선택된 디자인이나 근접 디테일 개선의 성공 사례로 분류하지 않는다. 크게 다른 초기 매스에 고정된 후속 시퀀스가 작동하는지 확인한 배리에이션 검증으로 보존한다.

변경 범위
G0의 입력 생성 방식과 매스 설계값을 변경하였다. 기존 seed_mass.legacy_core의 고정된 큰 접힘을 유지한 채 반지름만 바꾸는 방식에서, 이미 존재하는 seed_mass.evaluate를 사용한 중앙 팽창 입력으로 전환하였다. 따라서 G0 자체의 수식까지 그대로라는 의미는 아니다.
입력은 같은 25 ring / 16 sector 폐합 quad carrier, 같은 material chart와 축 정렬을 사용한다. G0 제어 정점 402개 중 401개가 이동하였다. 기존과의 최대 정점 거리는 약 1.572이며, face와 chart는 동일하다.
반지름 제어값: [0.44, 0.50, 0.66, 1.15, 1.85, 1.15, 0.64, 0.44]
valley: 0.18. 중앙 X/Y return과 중앙 diagonal event를 입력으로 사용하였다. 세부값은 RECIPE_EARLY.json과 INPUT_SCOPE_VERIFICATION.json에 보존하였다.

고정한 후속 규칙
G1–G7의 기하 연산, 선택 모드, 순서와 수치는 변경하지 않았다. Task36 분할, 초기 유한 Mandelbulb 형상장과 이동 예산, G2 return, G3 wall/root/sidewall, G4 중립 CC, G5 방향성 분할, G6 DEPTH_08/MIDDLE, G7 표면 분할과 연결 접힘 및 마무리 delta filter를 기존 함수 그대로 호출하였다.
초기 고정 규칙 8개와 후기 선택 규칙 6개의 값 일치를 확인하였다. 국소 PCA, rail, 법선, 위상 및 소유 관계는 새 메시에서 계산하였다. 기존 최종 메시나 변위 배열을 새 형상에 복사하여 결과를 만들지 않았다.
새 G0 외의 후속 파라미터 조정, 후보 검색, 새로운 레퍼런스 조사와 추가 알고리즘 개발을 진행하지 않았다.

실제 저장 순서
G00_INPUT → G01_ANCESTRY → G02_OVERLAP → G03_WALL → G03_ROOT → G03_SIDEWALL → G04_NEUTRAL → G05_DIRECTIONAL → G06_DEPTH08 → G06_MIDDLE → G07_SURFACE → G07_LINKED_RAW → G07_LINKED_FINISHED → G07_WIDE_RAW → G07_FINAL
G 번호는 quad subdivision 횟수이다. 같은 G의 root/sidewall/field/finish 상태를 추가 세대로 세지 않는다. 초기 Mandelbulb 내부 iteration은 G 번호와 별개이다. G7의 최근 접힘은 새 Mandelbulb 적용 결과가 아니다.

실행과 메시 검증
단일 명령으로 15개 상태를 순차 생성하였으며 생성 시간은 663.828초, 약 11.1분이다. 렌더와 정리 시간은 포함하지 않는다. 최대 RAM 사용량은 측정하지 않았다.
11개 상태는 실제 native 메시를 포함한다. G7 중간 상태 4개는 control과 evidence만 저장하였으며, 해당 상태의 native 면적 검사를 수행했다고 표현하지 않는다. 최종 G7은 native 메시를 포함한다.
최종 제어 정점: 7,038,978. 제어 quad: 7,038,976. Native 삼각형: 28,155,904.
최종 finite, 폐합·방향 일치, 단일 control component, Euler 2, orphan 없음과 native 최소 면적 검사가 통과하였다. 최종 native 최소 삼각형 면적은 약 8.928e-10이다.
실제 control 좌표 및 방향 있는 control face의 X/Y 반사 대칭을 검사하였다. 최대 좌표 오차는 각 축 약 1.868e-12, 허용오차는 1e-9이다. Native quad-centre fan은 확인된 control 반사 관계를 계승하며, native 삼각형 전체를 독립적으로 정렬해 비교한 검사는 수행하지 않았다.
generation.json 안의 checks.symmetry_scope에는 재사용 함수의 과거 pending 문구가 남아 있다. 실제 이번 대칭 결과는 top-level symmetry 및 SUMMARY.json의 final_symmetry에 기록되어 있다. 원본 생성 기록은 사후 수정하지 않았다.
독립 전체 재생성, 자기교차 검사와 제작 가능성 검증은 수행하지 않았다. 서로 다른 임의 topology의 입력으로 일반화되었다는 증거가 아니다.

실제 이미지 비교
저장된 새 G0–G7의 정면·전체 사선 16장과 G7 본체·근접 사선 2장을 렌더하였다. 보존된 기존 SPAN G0의 native 메시를 동일 장면에서 2장 렌더하였다. 기존 최종 SPAN G7 비교는 최신 WIDE_ROOT_FINISHED의 실제 이미지 3장을 재사용하였다.
총 원본 23장을 사용하여 초기 비교 2장, 세대별 비교 2장, 최종 비교 3장을 구성하였다. 카메라, 재질, 조명, Blender 버전과 이미지 source SHA를 확인하였으며, 비교 원본에 crop/resize를 적용하지 않았다. 원본과 보드 경로는 images/SOURCE_LIST.json에 있다.
기존 최종 비교는 657b3ab927d067630071a12fc14bd2b0a8d0681e의 최신 모델이며, 과거 선호 형상으로 되돌아간 비교가 아니다.

시각 검토와 남은 한계
서로 다른 실루엣과 같은 주름·장식 언어의 전이는 확인된다. 그러나 이것이 두 디자인의 미적 우열 또는 근접 완성도를 증명하지는 않는다.
새 입력에서는 중앙의 수평 층띠가 강하다. 실제 progression에서 이 띠는 G1부터 관찰되며, 마지막 G7 디테일만으로 발생한 반복으로 보기 어렵다. 원인별 정량 분리는 이번 검토에 포함하지 않았다.
상부 결속 장식과 sidewall fan은 기존과 비슷한 높이에 남는다. 고정 material 창의 규칙은 동작하였으나, 새로운 중앙 팽창을 읽고 전체 장식 배치를 자동 재구성한 결과는 아니다.
긴 골과 넓은 면은 유지되지만, 근접 이미지에는 골 측면의 반복 삼각 패싯, 모서리 톱니와 찢긴 듯한 경계, 작은 독립 접힘이 부족한 넓은 면이 남는다. 이번 작업은 근접 디테일을 위한 새 기법의 검증이 아니다.
Root와 독립 검토자 whole_column_operator가 실제 7개 비교판을 모두 확인하였다.

G8에 관한 사용자 질의 · 실행하지 않은 예상
단순 중립 분할은 해상도와 매끄러움을 높이며, 새로운 작은 접힘을 자동 생성하지 않는다. 작은 파장의 별도 접힘 규칙이 필요하다. 현재 중앙의 수평 층띠를 세대 증가만으로 정리하기는 어렵다는 판단이다.
추가 topology 이벤트 없이 같은 4분할이면 G8 native 삼각형은 112,623,616개로 예상된다. 이는 계산상 규모이며 실제 생성·검증 수치가 아니다.
이번 G7 최종 상태의 파일 합계는 1,008,478,652 bytes, 전체 trial은 정리 파일 추가 전 3,817,593,272 bytes였다. G8 최종 상태의 3–4GB 언급은 같은 저장 방식의 거친 추정이며 압축률에 따라 달라진다. G8 RAM 사용량과 실행 시간은 측정하지 않았다. G8은 실행하지 않고 보류하였다.
