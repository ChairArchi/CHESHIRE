## Concrete structural path being implemented, no ornament result yet

Use the actual G6 MIDDLE wrinkle as the immediate parent. Its unwrapped phase can identify ancestry and confine a search; remeasure crest/shoulder geometry on the actual connected surface rather than declaring a world-axis or original macro theta direction to be the target.

1. Extract connected parent crest candidates with original surface correspondence. Use the saved registered MIDDLE phase, which was computed on incoming DEPTH08 XYZ before the MIDDLE displacement; recomputing the analytic formula on deformed MIDDLE would relabel the feature. Confirm actual cross-profile prominence and shoulders before declaring a phase contour to be a measured geometric ridge. Compute intrinsic transverse phase gradient and along-wrinkle tangent on the actual incoming geometry.
2. Establish a second coordinate along the measured crest from physical arc scaled by local parent width. Transport that row coordinate across the shoulder along transverse surface trajectories, preserving common row identity. This must not become an independent height cosine, a separately restarted phase on every face, or a world-space nearest-sheet projection.
3. Use these coordinates to construct a curved generating scaffold aligned with the parent. Field orientation alone does not supply row positions or physical spacing. The primary [Instant Field-Aligned Meshes](https://rgl.epfl.ch/publications/Jakob2015Instant) and [QuadriFlow](https://stanford.edu/~jingweih/papers/quadriflow/) explicitly address orientation and position constraints; they support this distinction, not the claim that automatic remeshing alone recreates Hansmeyer.
4. Recursively form actual concave compartments and shared raised ribs on that scaffold with modified subdivision. Opposite F/E/V class motion can build niches and rims; any equal-scale planar zero-mean derivation is not a global volume or macro-preservation guarantee.
5. Keep explicit shared junction cells/row identities at real splits and returns. Do not average unrelated scalar phases at overlaps. A quiet termination is preferable to independent overprinted patches but is not itself a solved junction design.
6. If transferring formed-minus-neutral geometry to the accepted carrier, use exact recorded surface/chart correspondence. Once scaffold connectivity changes, its point order and generation labels are new: do not claim original G3-to-G7 birth IDs still match. Differential transfer removes the neutral scaffold's displacement but does not guarantee preservation of macro folds; verify actual geometry and matched views.

The next meaningful gate is a connected actual rib/cell row that turns with one G6 S wrinkle, has transverse connections enclosing deep niches, and remains organized through a return junction. A bent amplitude mask containing unrelated teeth does not pass. Native geometry and matched whole/close views must show a visible improvement before any candidate is presented as a result. No such new result has been produced in this research phase.

Following the user's spine clarification, the single planned candidate uses a small number of canonical mirror-orbits of long, geometrically confirmed parent crests chosen by intrinsic salience and separation. A shared-base curved strip carries a continuous central stem, broad paired nodes and deep inter-node intervals. The node cage is formed in actual tangent/binormal/normal frames; it is not another function of cross-wrinkle phi alone. Two subsequent coupled subdivision passes form subordinate recesses inside those masses. The initial design ratios are base width about 0.65 times actual FULL shoulder width W, node pitch about 1.5 base widths and height bounded by 0.35 base widths and 0.6 actual parent depth. These are CHESHIRE design choices, not Hansmeyer's unpublished values. The earlier 0.13 width estimate was a first-order half-spacing proxy, not the full measured width; the actual probe's full-width median is about 0.308. Loop counts must close with integer phase and canonical reflection registration; SOURCE endpoints must taper with compatible boundary derivatives. New modules and a receipt-bound runner are being authored; formation waits for actual cross-profile confirmation.

## Earlier research and rejected implementation rationale

Hansmeyer's published method uses modified subdivision, spatial and generational weights, and face/edge/vertex normal displacement. The completed face contributions feed the new edge and vertex positions. CHESHIRE already contains this dependency in `src/cheshire/reference_subdivision.py`; importing another implementation alone would not reconstruct its inherited fold junctions.

- Primary paper: [Subdivision-based architectural form](https://archive.bridgesmathart.org/2010/bridges2010-167.pdf)
- [Digital Grotesque II](https://michael-hansmeyer.com/digital-grotesque-II.html) describes branching and porous geometry beyond the scope of CHESHIRE's current fixed-topology column surface. A surface-detail pass should not be represented as an implementation of that complete system.
- IAAC's [DragonSkin: Python for Grasshopper mesh subdivision](https://www.iaacblog.com/programs/dragonskin-python-for-grasshopper-mesh-subdivision/) describes recursive face splitting, offset depth, attractor curves and influence ranges. Its public project description does not supply an executable rule guaranteeing the preservation of prior ridges and ends.

Actual current bottleneck: inherited body sections contain axial reversals before the final normal fields. The G0-to-G4 read-only diagnosis confirms that negative material-meridian axial derivatives predate Task32 attached root/cap events. The source's original PCHIP section intentionally makes deep cups; the later fine fields are not their sole cause.

Development therefore treats two different scales explicitly: reconnect the inherited body returns in their material coordinates while preserving radial protrusion, then add a coupled displacement field on the actual finer V/E/F birth IDs. Keep the mature NESTED02 coordinates at every scale and prolong only new displacement so the fine source residuals are retained. These are CHESHIRE design operators, not recovered unpublished reference algorithms.

The first completed-face relief trial gave every face centre a stronger positive offset than its edge and vertex points. Its matched preview exposed a repeated cell/waffle motif and it was rejected. A continuous field requires balancing the completed-face contributions: on constant normals and constant desired displacement A, a new edge receives A/2 from its faces and needs A/2 directly; an old vertex receives A/valence from completed faces and needs the remaining A*(1-1/valence). This avoids assigning a gratuitous bump to every mesh cell.
