# 주름 접속과 부모에서 갈라지는 디테일 — 2026-10-15

**최신 지시:** 사용자는 G7 한정 교체 조건을 거두고, 보유 기술을 사용해 한스마이어에 최대한 가까운 아름다운 결과를 요구했다. 미비하거나 좋지 않은 후보는 보여주지 않는다. 이후 “한스마이어는 장식이 주름을 따라 배열되는데 우리는 그렇지 않다”고 바로잡았고, 계속 리서치하며 방법을 생각하라고 했다. 기존 장식 배치가 이미 옳다는 전제로 새 형상을 생성하지 않는다.

**마지막으로 확인한 조형 목표:** “우리의 주름은 좋은데 이게 그냥 천 같은데. 척추마냥 새로운 장식이 타고 흐르면 진짜 괜찮을 것 같다.” 좋은 주름을 바탕으로 두고, 그 곡선을 따라 두께·마디·깊은 사이 골을 가진 연결된 입체 장식이 흐르도록 한다. 척추는 구조적 연속성과 리듬의 비유이며 literal 뼈 모양이나 전체 표면의 균일한 셀 덮개를 요구한 것이 아니다. 작은 평행 주름을 더하는 방식으로 이 목표를 충족했다고 보지 않는다.

**현재 상태:** NESTED02가 계속 기준이다. trial13–17은 이를 대체하지 않는다. [trial13](TRIAL13_REVIEW.md), [trial14 중단](TRIAL14_STOPPED.md), [trial15](TRIAL15_REVIEW.md), [trial16](TRIAL16_REVIEW.md), [trial17](TRIAL17_REVIEW.md)에 실제 완료·실패·미채택 상태를 구별했다. trial17 생성·렌더·PLY 내보내기는 완료됐지만 조형 개선으로 채택하지 않았다. 새 Hansmeyer 재구성 모델·렌더는 아직 생성하지 않았다. G8은 실제 실행하지 않았다.

**현재 구현 준비:** 마지막 척추 비유에 맞춰 단일 입체 장식 후보의 모듈을 작성 중이다. `native_strip_surface.py`는 동일한 연결 표면에서 실제 횡단 단면·어깨를 측정하고, `recursive_spine_operator.py`와 `run_spine_reconstruction.py`는 실제 폭에 맞춘 곡면 strip의 공유 줄기·마디를 형성한다. 실제 측정 확인 전에는 형상 실행하지 않는다. 새 렌더 adapter는 기존 NESTED02 기준 사진을 재사용하고 새 실제 native의 close만 먼저 검수한 뒤 동일 세션에서 context를 렌더하도록 준비한다. 이 문장은 구현 진행 상태이며 아직 결과가 있다는 뜻이 아니다.

**지금 근거가 있는 차이:** 현재 CHILD/SMALL은 같은 G6 MIDDLE 위상의 함수로 평행 단면을 더 잘게 만든다. 공식 상세 이미지에는 큰 주름을 따라 이어지는 2차원 셀·리브·깊은 홈의 조직이 보인다. 검토 중인 변경은 G6 주름 자체의 실제 길이·횡단 좌표를 만들고 그 곡면 격자에서 연결된 장식을 재귀적으로 형성하는 것이다. [최신 원문·코드 대조와 설계](RESEARCH.md), [8개 면의 국소 방향 감사](DIRECTION_ALIGNMENT_AUDIT.json)를 먼저 읽는다.

**수치 해석의 정정:** MIDDLE 위상과 원래 material θ 행의 중앙값 74.29° 차이는 NESTED 장식이 G6 주름과 어긋났다는 증거가 아니다. CHILD/SMALL의 이상적인 등위선은 MIDDLE과 평행하다. 기존 quad의 모든 변 중 MIDDLE 등위선에 가장 가까운 변도 표본 중앙값 31.67°지만, 이 역시 8개 면의 국소 격자 감사이며 전체 형상의 성공·실패 판정은 아니다.

**실행한 효율적 구조 확인:** 기존 저장 표면에서 phase가 가리키는 주름 후보 경로를 native 연결 ID로 한 번 추적했다. 8.24초에 규칙적인 loop 26개·열린 경로 24개를 얻었고 모든 노드에 연속 호 길이 좌표를 부여했다. 새 장식 모델·렌더를 만든 시험은 아니다. [실제 경로 증빙](../hansmeyer_reconstruction_20261015/phase_curve_probe01/PHASE_CURVE_GRAPH.json)과 [척추형 입체 장식 내부 검수 기준](HANSMEYER_STRUCTURE_GATE.json)을 보존했다. 후보 경로가 실제 geometric ridge라는 확인과 접합·폭 확인은 아직 남아 있다.

**실제 횡단 확인:** [native_strip_probe01](../hansmeyer_reconstruction_20261015/native_strip_probe01/NATIVE_STRIP.json)에서 33×33개 표본 모두 같은 연결 sheet를 따라 도달했고, 31/33개 단면에서 실제 양의 돌출을 확인했다. 전체 폭 중앙값 0.30794와 돌출 중앙값 0.07180을 기록했다. 후보 생성 준비 중 최초 preflight는 지나치게 강한 D/W 일률 조건 때문에 결과 내보내기 전에 중단됐다. 형상·가중치는 그대로 두고, 실제 표면 확인과 눈에 보일 마디 높이 조건을 분리한 새 runner v2를 준비한다. 미적 후보를 반복 비교하는 시험은 아니다.

**현재 우선순위:** 아름다움, 눈에 보이는 형상 발전, 다른 기둥에도 적용할 수 있는 생성 원리가 우선이다. 밀도·깊이·곡률 마스크만 바꾸는 반복 시험을 하지 않는다. 새 후보는 실제 G6 주름을 따라 종방향 배열과 횡방향 연결이 함께 형성되고 접점까지 조직되는지 내부 검수한다. 계산량·용량 최적화는 형상을 확보한 뒤에 한다. 아래 초기 진단은 역사적 증빙이며 최신 조형 성과나 확정된 해결책이 아니다.

## 작업 기준

기준 형상은 기존 NESTED02이다. 원거리의 바로크적 흐름, 세로 리본, 큰 주름과 돌출뿐 아니라 말려 들어가는 림의 깊이와 그림자도 조형 자산으로 취급한다. 컵형이라는 이유만으로 전부 펴지 않는다. 실제 개선 판단은 같은 카메라의 근접·몸체·전체 이미지로 한다. 수치상 역전 감소와 조형 성공을 구분한다.

사용자와 중간 방향 점검을 완료했다. 한스마이어·IAAC 수준의 재귀적 형성 원리와 다층 디테일을 목표로 하되, CHESHIRE의 주름 언어를 살린다. 큰 형상에서 작은 접힘이 생기고 갈라져 이웃 및 부모로 연결되는 관계가 읽혀야 한다. 여러 원리는 검토하되, 비슷한 파라미터의 반복 시험이나 밀도 증가만을 성과로 보고하지 않는다.

## 확인한 구조 원인

보존된 실제 G0–G4 자료를 읽었다. material meridian에서 음의 dZ/dt는 이미 G0에 30개, G1에 102개, G2에 566개, G3 WALL에 1,996개 있다. G3 ROOT·SIDEWALL 추가 전후 이 개수는 그대로다. 따라서 몸체의 컵형 말림은 Task32 cap이나 마지막 G7 하위 장식만의 산물이 아니다. 초기 PCHIP 단면이 깊은 컵을 의도적으로 구성하며, 후속 주름은 이 표면을 따른다.

이 진단은 음의 기울기를 모두 오류라고 판정하는 근거가 아니다. 깊은 말림과 겹침을 만드는 같은 형성 원리가 어색한 접속과도 관련되므로, 조형 판단이 필요하다.

trial01은 성숙한 NESTED02의 G5 ID 표본, trial02·03은 G6 ID 표본으로 표시한 사전 검토이다. 당시 과거 G5/G6 형상을 재사용하거나 G7 native를 간소화한 파일이 아니다. 정확히 현재 G7의 해당 old-ID 좌표를 샘플링하고 해당 계보 quad fan으로 표시했다. 600px 사전 검토의 면각 차이를 기존 실제 G7·900px 대비 개선 또는 악화의 근거로 사용하지 않았다.

첫 면 중심 relief에서 드러난 격자는 같은 평면·같은 상수 field에서도 face/edge/vertex의 이동량이 달랐기 때문이다. 새 연속 field는 completed-face 기여를 포함하여 상수 field에서 모든 V/E/F 점이 같은 변위를 갖도록 균형을 맞춘다. 이에 대한 평면 내부 및 zero-gain 검증을 완료했다.

단순 harmonic 위상 psi=m*phi+.3*sin(phi)는 dpsi/dphi>0이므로 새 Y 분기를 만들지 않는다. 이 한계를 확인하고, 최종 후보에서는 실제 부모 반경 굴곡에서 event 구간을 측정하여 뿌리와 끝에서 합류하는 daughter 접힘을 구성하는 별도 연산으로 진행한다. 완성 결과·경로·검증은 최종 기록에서 확정한다.

## 보존과 구현 원칙

원본 NESTED02와 기존 연구 코드는 수정하지 않는다. 새 실험은 `E:/CHESHIRE_DATA/experiments/fold_junction_development_20261015/`에, 새 실행 코드는 동명의 experiments 폴더에 둔다. 성숙한 G7을 각 규모의 기준으로 사용하고 새 변위만 실제 V/E/F birth ID로 운반하여 원본의 미세 잔차를 유지한다. 출력 세대 번호는 G7이며 새 G8 또는 topology event로 부르지 않는다.

trial03 실행 뒤의 경계 고정 수정본은 `axial_reconnect_v3.py`에 별도 보존했다. `axial_reconnect_v2.py`는 trial03의 실제 실행 snapshot으로 복원하여 해당 모델의 코드 증빙을 유지했다. 네 개의 작은 음의 경계 기울기를 없애는 수치 조정은 최종 조형 방향을 결정하는 근거로 사용하지 않는다.

공개 기술 검토의 출처와 범위는 [RESEARCH.md](RESEARCH.md)에 있다. 현재까지 전역 self-intersection과 제작 적합성을 증명한 결과는 아니다.
