# trial13 — 실제 생성은 확인, 조형 결과는 미채택

`trial13_causal_parent_generation`의 동일 조건 CONTROL/FORMED native 근접 렌더를 직접 비교했다. 큰 S 흐름과 빈 넓은 면, 기존 말림 끝의 인상이 거의 같다. 읽히는 하위 주름이나 새 조형적 위계가 생겼다고 판단할 수 없어 **채택하지 않는다**. NESTED02는 별도의 기존 설계 기준이며, 이번 인과 비교의 CONTROL은 동일한 실제 G6에서 만들어진 중립 G7이다.

실제 G6 부모 family 4를 새로 측정하고, 완성된 face가 edge/old-vertex carrier에 전달되는 순서를 구현했다. 현재 위치를 바꾼 질의와 중립 위치의 반사실 질의도 달랐다(E 최대 `0.00030008`, V 최대 `0.00014838`). 이는 실제 위치 피드백의 증거다. 아름다운 자식 형상이나 반복 가능한 생성 원리를 확보했다는 증거로 해석하지 않는다.

## 새 골 0/65의 정확한 의미

기존 측정기는 음의 새 골만 찾았기 때문에 `0/65`가 모든 새 relief의 부재를 뜻하지는 않는다. 저장된 65×129 native 측정 배열을 추가로 읽고, 각 행의 실제 shoulder 25–75% 내부에서 양·음 방향을 모두 검사했다. 동일 prominence 기준 `max(.002,.003*부모 폭)`에서 **양의 변위 봉우리는 15/65행**, 음의 변위 골은 0행이었다. 새 normal 변위의 중앙값은 `0.0000450`, p90은 `0.002824`, 최대는 `0.007329`다.

현재 형상 자체의 extrema는 CONTROL crest 118개/groove 114개에서 FORMED 119개/115개로 거의 유지됐다. CONTROL extrema의 ±2샘플 안에 대응점이 없는 FORMED extrema는 crest 1개, groove 2개다. 이 위치 비교는 보조적인 이산 표본 판정이며, 연속된 새 자식 주름의 검출 증명은 아니다.

## 왜 변화가 약한가

실제 FACE 요청의 B/N RMS는 `0.003435 / 0.001732`이고 변위 에너지의 79.7%가 B 방향이다. 대부분 접선 재분배와 작은 양의 normal uplift였다. norm cap이 주된 억제 원인인지까지 분리 검증하지 않았으므로 단정하지 않는다.

`qN=.65` 원본 형상장 slice의 음의 N peak는 `-0.010899`였으나 Gaussian 처리 후 `-0.000007447`로 약 1,463배 약해졌다. 양의 peak는 `.115641→.052445`로 남았다. N blur는 17개 샘플 축에서 σ=6.6876(정규화 N 약 `.418`)이므로 좁은 안쪽 로브를 크게 지웠다. 원본의 거의 전부가 0이었던 영역에도 작은 양의 응답이 퍼졌다. 현재 필드를 단순 증폭하면 새 골보다 기존 면의 부풀림이 커질 가능성이 있다는 해석이 타당하다. 미적 원인을 독립 실험으로 분리한 결과는 아니다.

또한 qT/qB는 material arc label에 고정되고 실제 XYZ는 qN에만 들어간다. B/T 이동이 같은 형상장의 B/T 좌표에 다시 반영되지 않으므로 **완전한 3D 부착 체적의 역좌표 변환은 아니다**. 실제 잔차의 B/T 투영을 추가하는 것은 1차 보정이며, 정확한 곡면 역변환에는 reference surface Jacobian 또는 국소 역해가 필요하다. 소유권과 보호 범위는 계속 원래 material 영역에 남겨야 한다.

이 기록은 실패한 조형 후보의 인과·보호 경계 증거를 보존한다. frozen runner/operator/helper와 E 드라이브 원본은 수정하지 않았다. 새 실행이나 G8 채택의 근거로 사용하지 않는다.
