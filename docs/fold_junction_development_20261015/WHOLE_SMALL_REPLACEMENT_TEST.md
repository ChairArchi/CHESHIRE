# 전체 소주름 Mandelbulb 교체 테스트 — 2026-10-15

사용자 지시: 큰 주름을 두고 일정 크기 이하의 국소 주름을 Mandelbulb로 덮는 테스트를 실행한다. 이는 앞선 한 부모만 시험하거나 차분한 면을 우선하는 실행 제한을 변경하는 명시적 지시다. 이 결과는 우선 비교용 시험본이며, 아름다운 최종안으로 자동 채택하지 않는다.

## 고정한 한 가지 설정

- 원본 비교: NESTED02 실제 G7, 14,004,226 native 정점 / 28,008,448 native 삼각형.
- 명목상 물리 크기 경계: 모델 단위 **0.30**, 높이의 약 **3%**. 모든 SOURCE/WALL/CAP 역할을 처리하며 카메라 패치나 특정 부모 마스크를 사용하지 않는다.
- 기존 후반 G5/G6/MIDDLE/CHILD/SMALL 형성 성분을 포함하지 않는 실제 G04_NEUTRAL에서 시작한다. 이미 G4에 들어 있는 작은 변형도 전체 메시의 물리 길이에 따른 intrinsic 필터로 줄인다. 그러므로 기존 소주름 위에 새 필드를 더하는 trial11과 다르다.
- 실제 quad fan 면적에 따른 질량과 실제 edge 길이에 따른 양의 graph stiffness로 4차 저역통과 필터를 계산한다. 명목상 파장 응답은 `1/(1+9*(cutoff/wavelength)^4)`다. 경계 파장 0.30은 10%, 5배인 1.50은 약 98.58%가 남는 완만한 전이다. 불규칙 quad의 실제 의미론적 주름 폭을 정확하게 분류하는 이진 경계는 아니다. 후반 성분 제거에는 경계보다 긴 일부 성분도 포함될 수 있다.
- 같은 실제 ancestry의 중립 CC로 G4에서 G7까지 올려 매크로 곡면을 얻는다. 원본과 동일한 native 연결을 사용한다. 이 단계에도 완만한 smoothing이 있어 큰 능선·실루엣을 정확히 고정한다고 주장하지 않는다.
- finite **power8 / 8 orbit iterations** Mandelbulb를 3차원 구면 방향으로 평가하여 바깥쪽 radial boundary를 얻는다. 방향별 81개 반경 표본 뒤 12회 이분 탐색을 사용한다. 이를 전체 매크로 곡면에 연속적으로 매핑하여 새 기하를 만든다. 법선 진폭은 **0.035**, 같은 boundary의 기울기에서 얻은 작은 접선 이동을 포함한다. 각도 매핑 주기는 `4*cutoff=1.20`, power8의 명목상 큰 lobe 간격은 약 **0.15**다.
- 이는 실제 3D Mandelbulb의 표본 경계로 만든 곡면 형상이며, Mandelbulb 전체의 체적 topology·분기·관통공을 재현하는 것은 아니다. 원래 무한 fractal의 정확한 거리장도 아니다.

## 실행과 산출물

새 실험: `E:/CHESHIRE_DATA/experiments/fold_junction_development_20261015/trial12_all_small_mandel_replacement/`.

실행 갱신: 위 폴더는 행렬 계산의 과도한 실행 시간을 줄이기 위한 런타임 재시작 기록만 보존한다. 형상 파라미터와 알고리즘을 바꾸지 않고 BLAS/OMP/MKL 스레드를 1로 제한한 실제 재개 폴더는 `trial12b_all_small_mandel_replacement/`다. 첫 실행에서 새 모델·렌더는 생성하지 않았다. 이는 별도의 조형 파라미터 시험이 아니다.

최종 계산 갱신: G4 직접 분해가 계속 병목이어서 `trial12b`도 모델 생성 전에 종료·보존했다. **실제 완성 형상은 `trial12c_all_small_mandel_replacement/`**다. 실제 G03_SIDEWALL 전체 27,354개 제어점/27,352개 quad에서 같은 명목 물리 필터를 적용하고, 동일 ancestry의 CC 네 번으로 G7에 올렸다. 필터는 6.18초, 전체 생성·검증은 75.41초에 완료됐다. cutoff 0.30 / power8 / orbit8 / amplitude0.035는 그대로다. G3 필터 후 세분은 G4 필터 후 세분과 수치적으로 같지 않으며, 크기 분류의 더 거친 근사다. G7의 표시 밀도가 이 분류 근사를 복구하지는 않는다.

생성 검증: 전 제어점 7,002,114개가 교체 대상이며 XY 위치 대칭 오차는 0이다. 새로운 Mandelbulb 기하의 최대 변위는 0.03561, 원본에서 전체 교체 후 최대 변화는 0.16117이다. 매크로 캐리어와 원본 좌표 차이는 median0.02906/p990.08082/max0.12853이다. 큰 주름을 수학적으로 완전히 고정한 결과가 아니다. 실제 native 삼각형 28,008,448개의 최소 면적은 양수이며, 원래 삼각형과 법선 내적이 음수인 비율은 29.63%다. 이 수치는 작은 굴곡 제거·새 곡면 반응에서 큰 방향 변화가 있다는 뜻이며, self-intersection이나 제작 안전성을 증명하지 않는다. 같은 카메라의 실제 화면에서 별도로 판단한다.

같은 카메라·조명·재질·900px·flat shading에서 원본 CONTROL과 교체 FIELD의 근접·몸체·전면을 렌더한다. 사용자가 지시한 비교 테스트이므로 실제 전체/디테일 PLY와 오프라인 비교도 `research_probe`로 제공한다. 아름다움이나 제작 적합성은 내보내기 성공과 별개다. 수치·실행 상태·최종 시각 판정은 완료 뒤 기록한다.

## G8 관련

사용자가 G8을 피하는 이유를 물었다. G8을 금지하거나 하드웨어 부담 때문에 배제하지 않는다. 이번에는 크기별 교체 연산을 먼저 분리하여 확인한다. G8의 실제 새 control 배치와 필드 재평가를 실행한 기록은 아직 없으며, G8이 도움이 없다는 인과 검증을 한 것도 아니다. 같은 quad 세분을 한 번 추가하면 native 삼각형은 약 4배인 **112,033,792**개가 된다. 현재 단계 번호와 새 형성 정보·실제 표현 해상도를 구분한다.

실제 보존 G7 control에서 16,384개 face-index 균등 표본 quad의 65,536개 boundary edge instance를 읽었다. SOURCE 14,831 / WALL 920 / CAP 633 quad가 포함된다. 길이는 median=0.0040732759, p90=0.0082992927, p99=0.0147462892다. 이번 명목상 주요 lobe 간격 0.15당 median 기준 약 36.83개, p90 기준 약 18.07개 변이다. 원본 G7 표본에서는 주요 lobe 표현 밀도가 확보된 것으로 보이나, 새 곡면 전체의 최악 위치·더 작은 fractal harmonics까지 입증한 것은 아니다. 표본은 area-weighted도 unique-edge 전수조사도 아니다.
