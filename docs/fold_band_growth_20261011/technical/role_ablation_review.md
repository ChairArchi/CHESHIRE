# Resolution and offset-scale ablation: independent visual review

Reviewed SPAN_SPARSE G00, ROLE_SPARSE_VERTEX_FACE G01, and ROLE_ABSOLUTE G1?G3 actual front, oblique and side renders.

The sparse support-relative trial makes cells wider but changes mass relations only weakly; broad facets of the sparse sampled input remain prominent. Lower sampling alone does not create a stronger meso structure.

The absolute-scale trial produces a meaningful visual difference. From G2, deeper cellular walls and transverse lips traverse valleys, necks and shoulders, forming a legible web-like relief in three dimensions. The original large grooves remain visible at G3. This pattern has value as a second surface scale and should not be rejected merely because it is regular or web-like.

Its achievement is nevertheless specific: it strengthens a secondary geometric network following the existing folds; it does not create new shoulders, node relationships or a significantly different macro silhouette. G2 has the clearest balance of broad folded surfaces and cellular relief. G3 is worth preserving as the more intensive organization, although dense upper cells compete with the source large folds.

Recommendation: retain ABSOLUTE G2 and G3 as distinct intensity checkpoints, with G2 the visual representative. The present ablation provides enough evidence to stop without a new initial-design branch or additional operators. No image-based self-intersection or fabrication claim is made.
