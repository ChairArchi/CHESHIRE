이 문서의 역할

현재 결과로 이어진 선택 계보를 기록에서 복원한 문서이다. 새로운 형상을 생성하지 않았다.
전체 실험 목록이나 처음부터 예정된 하나의 성장식으로 설명하지 않는다.
각 단계의 원리·선택값·입출력을 고정하여 다음 개발과 배리에이션의 출발점으로 사용한다.
여기에 기록한 값은 현재 결과의 레시피이며 이후 설계에서 바꿀 수 없는 제약이 아니다.
선택 계보는 현재 개발 체크포인트의 재현 경로이며 WIDE_ROOT의 밀도나 최종 디자인을
사용자가 채택했다는 의미는 아니다. 사용자 디자인 선택으로 확인된 기준은 MIDDLE의 여백이다.
원본 코드·메시·체크포인트·기존 검증 기록은 수정하지 않았다.

판정

현재 기둥은 G0에서 실제 quad subdivision을 7회 거친 결과이다.
각 단계는 수식과 코드로 정점을 계산한다. 개별 정점을 손으로 조형한 결과가 아니다.
다만 같은 성장식 하나를 일곱 번 반복한 것도 아니다.
연구 중 이미지와 검증을 보고 서로 다른 연산·계수·활성 영역·경로를 선택하였다.
가장 정확한 표현은 '선택된 단계별 레시피를 가진 절차적 생성 방식'이다.
단계별 재현 근거는 보존되어 있으나 최신 전 과정을 한 번에 실행하는 통합기는 아직 없다.
이번 작업은 계보·수식·의존성의 문서화이며 통합 실행기나 새 입력 일반성의 검증은 아니다.

번호를 읽는 원칙

G = 실제 quad subdivision 횟수이다. Task36의 custom 분할도 포함한다.
G1·G2는 표준 중립 Catmull–Clark가 아니다. G3의 interpolating 분할도 중립 CC가 아니다.
선택 계보의 중립 CC는 G3→G4와 MIDDLE G6→G7이다.
G4→G5와 G5→G6는 CC 기반 위치 계산에 방향성 법선 제어를 결합한다.
연결 면 생성 사건, 형상장 적용, 법선 변위와 변위 평활화는 G를 증가시키지 않는다.
Mandelbulb 내부 iteration 4·8회는 G1·G2와 다른 개념이다.
G6·G7 뒤의 추가 처리는 단계 이름으로 구분하고 새 G 번호를 붙이지 않는다.

배리에이션: 가능한 것과 아직 준비되지 않은 것

현재 같은 parametric seed 계열의 큰 형상·PCHIP 프로필·방향·진폭·파장·띠 폭을 바꾸는 것은
기술적으로 가능하다. 공통 quad 연산과 후반 build는 특정 정점 수만을 요구하지 않는다.
세대별로 다른 연산을 쓰더라도 그 조건과 순서를 명시하면 하나의 절차로 구성할 수 있다.
초기·중간 일부 단계는 SPAN/COUNTER 두 입력 적용·재생 기록이 있다.
그러나 최신 MIDDLE→최종 G7의 전체 경로는 SPAN 한 기둥에서 확인했다.
임의의 새 메시나 다른 입력에서도 같은 조형 품질을 낸다는 증거는 없다.

현재 연결이 필요한 부분은 세 가지이다.
1. 초기 매스·이벤트·단계 선택값을 코드 내부 상수 대신 하나의 외부 recipe로 전달하기.
2. 단계별 출력을 다음 단계의 실제 입력으로 전달하고 chart·PCA·role·반사 ID를 함께 운반하기.
3. G0~G7 및 G6/G7 추가 변형을 구별하여 저장하는 하나의 순차 실행 경로로 연결하기.
이번에 이 통합을 구현하거나 다른 기둥을 생성한 것은 아니다.
새 형상법 전체를 다시 연구할 필요와, 기존 연산을 연결할 구현 작업을 구분한다.

초기 매스 비례·큰 return 위치, 활성 창, root/child 위치와 크기, 단계별 연산 선택,
파장·진폭·위상·PCHIP 가중치·마감 횟수는 작성하고 실험에서 선택한 값이다.
최적의 값이나 레퍼런스 원본 수치로 확인된 값이 아니다.
현재 형상을 처음부터 예정한 자동 진화 결과로 소급하여 설명하지 않는다.
반면 선택 후의 정점 배치·분할·반사·변위 계산은 명시된 코드가 수행한다.
앞으로 변경할 때는 입력, 수식, 파라미터, 실행 순서 중 무엇을 바꿨는지 기록한다.
G가 같고 topology가 유지된 수정은 단계 버전으로 표시하여 분할 세대와 혼동하지 않는다.

현재 한계와 보존한 미실행 가설

최신 실제 렌더에서는 중간 골의 깊이와 하단 말림으로 이어지는 흐름이 개선되었다.
작은 골의 독립적인 위계와 근접 삼각 면 억제는 미완이며 넓은 밝은 여백도 줄었다.
기술적 검사 통과를 조형 완성이나 임의 입력 일반성으로 해석하지 않는다.
누적 변형이 어색함에 기여했을 가능성은 있으나 동일 입력 대조로 원인을 분리하지 않았다.

사용자가 제안한 '초기 Mandelbulb + G7 최종 Mandelbulb 디테일'은 미실행 마감 가설이다.
현재 선택 계보에 G7 Mandelbulb를 적용한 것으로 기록하지 않는다.
초기 nearest-outside 이동을 그대로 재적용하는 것과 얕은 법선 relief로 사용하는 것은
서로 다른 연산이며, 어느 쪽도 현재 결과의 개선으로 검증되지 않았다.
이 가설을 실행 지시나 필수 개발 조건으로 취급하지 않는다.

증거와 확인 범위

LINEAGE.json: 실제 15개 receipt, 16개 입력 관계, G 번호, 코드 해시, 원본 경로.
receipts/: 원래 generation.json 15개의 바이트 사본. 원본을 수정하지 않았다.
초기 G1/G2 receipt에는 당시 부모 control hash가 없다. 현재 관찰한 SHA를 당시 binding으로
소급하지 않는다. WALL 이후에는 실제 부모 SHA 연결을 확인할 수 있다.
이번 확인은 작은 receipt·현재 보존 코드 해시·메타데이터 의존 관계를 대상으로 한다.
새 메시 생성, 최신 전 과정 독립 재생, 모든 NPZ 재해시, 새 렌더는 수행하지 않았다.
기존 단계별 검증의 범위는 각 원본 checkpoint를 따른다. 그 수치를 합산해 새 검사로 쓰지 않는다.
현재 최종의 폐합·연결·대칭 확인과 자기교차·제작 적합성 미검증도 기존 기록 그대로이다.
