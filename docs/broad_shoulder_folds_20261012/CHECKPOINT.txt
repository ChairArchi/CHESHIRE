실험 1 — 넓은 어깨의 중간 접힘

두 입력에 같은 작성 좌표 범위 s=.70–.87, theta=.90–pi/2−.005를 사용했다.
실제 G3 native 메시의 41×129 표본을 측정했다. 부모 중심선에 수직인 경계 chord 폭은
SPAN 최소 .565330 / 중앙값 .669397, COUNTER 최소 .650673 / 중앙값 .817161이다.
이는 자동 어깨 검출이 아니다. 최소 폭 .5와 변위 상한은 이번 비교의 작성 조건이다.

BASELINE, CLEAR_ONLY, BROAD_ACTIVE는 모두 실제 G6 대안이며 연속 세대가 아니다.
CLEAR_ONLY는 넓은 패치 안에서 기존 국소 벌브 마무리를 공통 부모 기준면으로 교체한다.
BROAD_ACTIVE는 같은 기준면에서 G4의 중간 능선·양옆 골과 G5의 작은 측면 접힘을
적용하고 G6로 세분한다. 패치 밖 BASELINE과 끝부분은 실제 native 좌표까지 정확히 보존한다.
부모 native 삼각형 법선을 실제 횡단 arc와 길이 방향으로 모아 PCHIP 보간한 방향을 사용한다.
새 Mandelbulb 계산은 수행하지 않았다. 기존 G3 형상 이력과 패치 밖 기존 디테일은 남아 있다.

시각 판정: 두 입력의 중간 능선·골 PASS, 큰→중간→작은 완성 계층 PARTIAL.
사선의 깊이와 긴 능선 연결이 읽히며 이전 COUNTER 판·입술 실패는 반복되지 않았다.
G5의 작은 크기는 충분히 구별되지 않고 큰 각진 면과 띠 모양 분절이 남아 있다.
전체 정면에서도 상부 어깨의 변화가 보이지만 전체 기둥의 디테일 완성을 뜻하지 않는다.

실험 2 — 실제 중간 능선 부모의 작은 뿌리 접힘

ROOTED_FANS는 실제 BROAD_ACTIVE G6에 한 번의 표면 변위를 추가한 대안이다.
세분 횟수는 늘리지 않았으며 G6를 유지한다. 같은 작성 규칙으로 한 기준 사분면에
6개의 사선 가지와 6개의 작은 자식 곡선을 두고 실제 입력 G6의 방향을 다시 측정했다.
곡선의 UV·삼각형·barycentric 좌표·XYZ 증거를 저장했지만 실제 능선 극대점의 자동
검출은 아니다. 최대 합성으로 겹침을 처리하므로 자식의 작은 볼록부가 가려질 수 있다.
실제 최대 추가 변위는 SPAN .0399999970, COUNTER .0399999998이었다.

시각 판정: 작은 접힘 계층 FAIL, 국소 방향 변화 PARTIAL, 미채택.
부모의 긴 능선과 골은 유지되지만 새 가지가 뿌리에서 말단까지 한 묶음으로 읽히지 않는다.
국소 주름·패임과 각진 면 분절이 주도한다. 기술 검증 PASS와 이 판정은 모순되지 않는다.

확인된 기술과 검증 범위

두 실험 모두 실제 입력에서 patch/frame/단계별 변위/최종 control·native 메시를 재생한
독립 VERIFICATION.json이 PASS다. 원본 해시, 실제 XYZ의 X/Y 대칭, 유한성, 양의 삼각형
면적, 실제 영역 밖·끝부분 보존 및 입력과 동일한 연결성을 확인했다. 닫힌 단일 몸체와
면 방향의 근거는 실제 동일한 faces 및 이전 검증 영수증을 연결하여 확인했다.
자기 교차·제작 가능성·구조 성능·임의 입력 일반성은 검증하지 않았다.

새 관련 단위 테스트 25개 PASS (15.47초). 전체 저장소 테스트를 의미하지 않는다.
Broad 실제 6개 상태의 24장과 fine 새 2개 상태의 8장을 렌더했다.
Fine 비교 검증의 총 32장은 기존 broad 24장을 포함한다. 이를 56개 고유 이미지로 합산하지 않는다.
모두 900px, 24 samples, 같은 광원·재질·카메라 조건의 실제 메시 렌더다.
렌더용 displacement/normal map이나 형상을 바꾸는 modifier는 사용하지 않았다.
각 단계 8개 비교 보드와 원본 경로·SHA256·카메라 영수증을 보존한다.

알고리즘으로 확보한 범위

같은 작성 창에서 실제 폭과 표면 방향을 측정하고, 중간 능선·홈의 크기를 폭에 맞추며,
대칭과 기존 영역을 보존하는 재현 가능한 연산자를 확보했다. 두 입력에서 시각적 중간
구조를 확인했다. 창의 위치, 곡선 배치와 일부 비율은 여전히 작성 값이다.
자동 특징 검출, 현재 부모 형상에 따른 재귀적 분기, 범용 디테일 엔진을 확보한 것은 아니다.

다음 개발 방향

한 구역의 소수 가지에 집중하여 부모 능선→작은 접힘→말단의 연속성을 먼저 확인한다.
실제 부모의 폭·홈 깊이·곡률과 지지 면을 다음 접힘의 위치·규모 결정에 사용하는 방식,
큰 각진 면을 남기는 초기 부모 생성 방식, 합성 시 작은 볼록부의 가시성을 검토한다.
이것은 후속 계획이며 이번 체크포인트에서 구현되었다고 주장하지 않는다.
두 입력, 같은 카메라, 명확한 크기 관계를 계속 판정 기준으로 삼는다.
임의의 변위 상한이나 기존 국소 면 보존을 영구 설계 조건으로 취급하지 않는다.
