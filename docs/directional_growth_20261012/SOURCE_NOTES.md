# Source and experiment boundaries — 2026-10-12

The [IAAC Mesh Subdivision project](https://www.iaacblog.com/programs/mesh-subdivision/)
was consulted again before this comparison. Its public process distinguishes
Mandelbrot-derived geometry, subdivision variants, and additional attractor
curves; depth and initial geometry also vary in its catalogue. Therefore the
catalogue is not evidence that one fixed input becomes more beautiful merely
by adding subdivision levels.

The [nearest-outside flow](https://www.iaacblog.com/wp-content/uploads/2020/12/group-4_python-presentation2.png)
and the [inside/outside radial flow](https://www.iaacblog.com/wp-content/uploads/2020/12/group-4_python-presentation4.png)
are distinct public paths. CHESHIRE's current comparison uses the first kind
of operation with a declared finite polar Mandelbulb reconstruction. The
original executable, exact 3D equation, coefficients, and final column recipes
have not been recovered. Task36 placement, the 4/8/18 escape schedule, guide
mapping and authored PCHIP return parameters are CHESHIRE choices.

## Why branch from G1

The previous ANCESTRY_STAGED G3 has useful deep cavities and nested folds,
but still repeats a transverse quad-derived grid. Standard CC averaging gain
is already zero. Relevant causes include uniform weighted stencil placement,
shrinking support-scaled offsets, and field displacement of old vertices
after Task36 temporarily retains them. Discrete nearest-target changes can
also contribute roughness. These are implementation observations and causal
hypotheses, not a claim that subdivision and fractals are incompatible.

Both new approaches start from the exact saved ANCESTRY_STAGED G1 control
checkpoint. The G2 comparison therefore has the same inherited first cycle
and one new cycle. A selected G3 adds one further cycle; it is not a G4 piled
onto the old final surface.

## Limits of the terms used

- V/E/F ancestry is birth lineage, not explicit crease-angle memory.
- A prescribed guide or curvature proxy is not a physical crease solver.
- Authored PCHIP radial/axial returns are geometric deformations, not folds
  spontaneously produced by the Mandelbrot equation.
- Retained old control vertices do not certify an unchanged physical surface:
  mean fans of nonplanar refined quads can differ.
- Symmetry is generated by mirrored displacement, without averaging old XYZ.
- No separate mesh smoothing pass, image synthesis, normal map, or rendered
  attractor curves are introduced.
- Intersections are recorded on selected results; collision repair, thickness,
  structure, fabrication, and developability remain outside this test.

## Additional existing response comparison

`face_geometry` and `all_geometry` are existing Task36 options, not IAAC
formulas. Signed neighbour-face/edge normal contrast changes the normal
coefficients; stencil and ancestry remain common. Face changes also feed the
coupled edge placement. In this recipe vertex_gain=0 removes direct vertex
normal offset, and vertex_memory=1 separately retains old Task36 vertices;
the subsequent field can still move them. These controls amplify contrast,
not smooth XYZ, and can enlarge convex panels rather than deepen nested lips.
Both were tested from the same actual OVERLAP G2 with the same G3 field.
