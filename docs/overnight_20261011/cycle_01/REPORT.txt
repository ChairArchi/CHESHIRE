CHESHIRE D / RETURN — 외부 조형 강화
2026-10-11 · 실제 메시 디자인 스프린트

판단
현재 컨셉을 바꿀 필요는 없었다. 기존 단면과 리브를 몸체와 함께 회전시키자 정면·측면·후면에서 방향 전환이 드러났다. 추가 리브나 면 수 증가 없이 세 방향, 총 네 메시를 만들었다. TORQUE R1을 우선 추천하고 KNUCKLE R2를 독립적인 비교안으로 남긴다. 최종 미적 선택은 확정하지 않는다.

TORQUE R1 — 연속적인 역방향 꼬임
RETURN G2의 발–기둥–어깨–중앙 결속을 유지했다. 하부의 감김, 중간의 반대 회전, 어깨로 다시 펴지는 리브가 외부 실루엣을 만든다. 독립된 마디를 적층하지 않고 하나의 몸체가 방향을 전환한다는 점이 가장 설득력 있다.
잃은 것: 정면의 개구부가 좁아졌고 상승 흐름은 더 격렬해졌다. 상부 중앙은 원형과 같아 무거운 V자 결속이 남는다. 넓고 비교적 조용한 면도 완전히 사라지지는 않았다.

KNUCKLE R1 → R2 — 결속과 팽창에서 일어나는 방향 전환
RETURN에서 분기했던 INFLECT G4의 낮고 가벼운 상부를 재사용했다. R1은 몸통의 팽창과 목 부분을 강하게 만들었지만 구슬 같은 반복으로 읽힐 위험이 컸다. 실제 렌더를 본 뒤 R2에서 중간 팽창을 줄이고 결속을 길게 연결했다. 회전과 구간별 차이는 유지하면서 분절의 과장을 완화했다.
잃은 것: R1의 공격적인 돌출과 극적인 음영이 줄었다. R2도 TORQUE보다 마디의 존재가 강하다. 가벼운 중앙 상부는 이번 회전의 성과가 아니라 INFLECT G4에서 물려받은 특징이다.

CONFLUX R1 — 기둥 회전을 상부 되접힘으로 전달
RETURN G2의 몸통 회전과 어깨 팽창에 실제 상부 되접힘을 결합했다. 사선·측면에서는 상부가 앞으로 돌아오는 사건이 보인다.
중단 이유: 중앙의 깊이가 3.34에서 3.71로 늘었고 V자 입술과 무거운 처마 인상이 강해졌다. 기하 검사는 통과했지만 현재 우선순위에서는 조형적 손실이 더 크다. 성공안으로 추천하지 않으며 실제 메시를 보존한다.

깊이와 개구부
Z=6의 실제 수평 단면 (상대 모델 단위, 폭 W / 깊이 D / 정면 투영 개구부 O):
RETURN G2     W 2.44 / D 3.92 / D:W 1.61 / O 5.43
TORQUE R1     W 3.17 / D 3.27 / D:W 1.03 / O 4.73
KNUCKLE R2    W 3.51 / D 3.00 / D:W 0.85 / O 4.40
CONFLUX R1    W 2.96 / D 3.74 / D:W 1.26 / O 4.91
일괄 깊이 축소 대신 기존 단면의 방향과 국소 비례를 바꿨다. 측면의 통짜 기둥은 완화됐지만, 더 넓어진 몸통은 개구부를 일부 침범한다. 원근 비교에서는 긴 통로보다 두꺼운 문틀과 여러 겹 처마로 읽힌다. 터널 문제가 완전히 해결됐다고 주장하지 않는다. O는 전체 통행 여유나 법적 치수의 인증이 아니다.

사용 자산과 검증
기존 RETURN의 플루팅·되접힘 메시, INFLECT의 단면 결속·상부 경량화, 기존 유한 회전 및 국소 단면 비례 조정을 재사용했다. 이번에는 추가 subdivision, Tissue, frame_bundle, 별도 shell, 접합 수리 없이 좌표만 변형했다. 생성한 한쪽 반을 반사해 좌우를 대응시켰으며 접힘을 정점 평균화하지 않았다.
새 네 메시 모두 311,298 정점 / 622,592 삼각형, 단일 폐합 성분이다. 좌우 반사 정점 오차 0, 원본 polygon 및 삼각형 연결 대칭 통과. 경계·비다양체·퇴화 삼각형 0, CGAL 전체 first-only 교차 검색에서 검출 쌍 0. OBJ/PLY 재읽기와 원본·설정 보존은 별도 기록한다. 새 기술적 실패는 없었다. CONFLUX의 중단과 KNUCKLE R1의 수정은 조형적 판단이다.
이 검사는 제작 인증이 아니다. 국소 최소 두께, 얇은 리브의 강성, 받침과 실제 축척·재료·접합 계획은 남아 있다. 기존 검증 기준을 유지했다.

다음 조절 변수
회전의 진폭·전환 높이·전환 구간 길이, 팽창과 결속의 폭, 몸통의 국소 앞뒤 이동, 어깨 되접힘 각도, 중앙 상부의 높이와 깊이. 주름 개수보다 이 변수들의 관계를 먼저 선택하는 것이 좋다.
RETURN G2, LINK G2, D_R2, A R3, B R2와 과거 실패 후보를 보존했다. 여기서 형태 생성을 멈추고 TORQUE의 연속성과 KNUCKLE의 구간 차이를 비교한다.
