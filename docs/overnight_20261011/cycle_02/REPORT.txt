KNOT R2를 추천한다. 기둥의 회전이 어깨에서 멈추지 않고 상부의 되감김으로 이어지며, 중앙은 높은 첨두보다 양쪽 질량을 당겨 모으는 결속으로 읽힌다. 기둥 중간의 팽창을 바깥으로 옮겨 개구부를 되찾았다. 최종안 확정은 아니다.

세 가지 접근과 한 차례 발전
SPLAY R1 — 낮고 넓은 멍에로 전환했다. 개구부는 시원하지만 상부가 차분한 들보로 읽혀 기둥의 꼬임과 긴장이 끊긴다. 조형적으로 중단, 실제 메시 보존.
CROOK R1 — 어깨와 중앙의 회전 방향을 달리해 안쪽 아치와 바깥 윤곽을 분리했다. 상부가 확실히 달라졌지만 수평 띠의 인상이 남고 자기교차가 확인됐다. 탐색 비교안으로 보존.
KNOT R1 → R2 — R1의 측면 되감김을 선택해 한 차례 발전시켰다. R2는 몸통 팽창을 더 바깥으로 이동하고 어깨를 벌리며 중앙의 결속을 다시 두텁게 했다. 독립된 마디 적층이나 새 장식 없이 기존 연결 메시를 변형했다.

얻은 것과 잃은 것
TORQUE의 큰 기둥과 기존 상부가 따로 읽히던 관계가 개선됐다. 바닥의 감김, 몸통의 역회전, 어깨의 상승, 중앙의 되감김이 서로 다른 사건으로 연결된다. 정면의 V자 첨두는 약해졌지만 후면에는 뾰족한 수렴이 남는다. 넓어진 포털은 공간성이 강해진 대신 기존의 수직 압축감과 중앙의 날카로운 긴장감을 잃었다. 어깨의 넓고 매끈한 면과 몸통의 구근성도 남아 있다. 미적 성공을 완결됐다고 보지 않는다.

실제 단면 비교: Z=6, 상대 모델 단위
                    기둥 폭 W   깊이 D    D/W    전 깊이 투영 개구 O
TORQUE R1             3.17       3.27     1.03       4.73
KNOT R2               2.77       3.27     1.18       7.69
CROOK R1              2.89       3.27     1.13       6.71
깊이를 일괄 축소하지 않았다. KNOT의 중앙 결속 깊이는 3.34→2.43으로 줄었지만 기둥 중간 깊이는 유지했다. 개구 O는 수평 절단을 전체 깊이에 투영한 빈 폭이며 전체 통행 여유나 법적 치수의 인증이 아니다.

사용 기술과 핵심 검증
보존된 TORQUE R1의 회전 리브·실제 메시, 기존 국소 단면 비례와 팽창/결속, 완전 단면의 유한 회전·되접힘, 재료 좌표와 반사 대응을 재조합했다. 추가 subdivision이나 Tissue는 사용하지 않았다. 모든 후보는 같은 원본 연결 구조이며 별도 shell이나 숨긴 수리가 없다.
KNOT R2: 실제 OBJ/PLY 반사 정점 오차 0, 원본 quad의 반사 연결성 확인. 단일 연결체, 경계·비다양체·퇴화 삼각형 0, 폐합 및 일관된 winding. CGAL 전체 first-only 탐색에서 교차 쌍 미검출.
CROOK R1: 같은 대칭·연결성·폐합 검사 통과, CGAL 교차 1쌍 확인 후 종료. 총 교차 수는 미집계이며 기술적으로 실패한 탐색안이다.
SPLAY R1 / KNOT R1: 빠른 연결성·폐합 확인과 실제 렌더만 수행. 자기교차 미검증.
두께·받침·재료·실제 축척·구조 성능·제작 접합은 모두 미검증. 제작 가능 모델이라고 주장하지 않는다. 회귀 테스트, 재현 검사, 대규모 해시 감사는 반복하지 않았다.

비교 자료: 01 기존/추천 정면·사선·측면 / 02 세 방향 / 03 KNOT 세대 변화 / 04 보존 후보 비교. 모든 영상은 실제 메시 렌더이며 카메라·배율·재료·조명을 공유한다. 01·04는 1200px/32 samples, 02·03은 800px/16 samples로 각각 맞췄다.
원본 TORQUE와 KNUCKLE R2, RETURN/LINK, A R3/B R2 등 기존 후보는 보존했다. 이후 조절할 가치가 있는 것은 어깨 면의 분화, 중앙의 앞뒤 결속, 바깥으로 이동한 팽창과 기단의 관계다. 여기서 추가 생성을 멈춘다.
