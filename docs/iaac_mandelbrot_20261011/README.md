# IAAC / Mandelbulb 시험 — GPT 검토 자료

[**FOR_GPT.md에서 시작하세요.**](FOR_GPT.md)

현재 형상은 실제 메시로 생성됐지만 **접힘선 기반 folding 구현은 아닙니다.** 유망 기준에 자기교차가 확인됐으며 제작 가능성은 미검증입니다.
