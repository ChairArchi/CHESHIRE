중간 시도와 실제 상태
앞선 rolled_end_rebuild/trial01, trial02는 각각 소유 계보와 투영 곡선 검사에서 중단되어 출력 메시가 없다.
rolled_end_rebuild/trial03은 실제 생성·렌더했으나 각진 판과 잘린 중앙 말림이 생겨 거부했다.
본 폴더 trial01의 VOLUME_JUNCTION_TARGET은 실제 voxel 외피에 국소 좌표를 투영했다.
투영은 원래 내부 면을 제거하지 않아 근접 개선이 충분하지 않았다. 이 후보는 채택하지 않는다.
coarse target 자체의 렌더도 보존했다. 큰 voxel 면과 전역 세부 손실 때문에 최종 후보로 채택하지 않는다.
volume_finish는 .00075H voxel, 표시 부위 Smooth 3회, Mirror, CC 마감 과정에서 OpenSubdiv 메모리 할당 오류로 중단됐다.
crash 로그는 __scrt_throw_std_bad_alloc 및 StencilBuilder 호출을 확인한다. 이 시도는 성공한 출력과 렌더가 없다.
volume_finish_v2는 같은 voxel·표시 부위 Smooth를 유지하고 CC의 limit surface를 끄고 quality=1로 저장했다.
v2의 실제 검사에서 주 연결 성분 이외 598개 작은 성분·고립점과 미세 반사 좌표 오차가 검출됐다.
volume_finish_clean은 v2의 주 연결 성분만 남기고 정점의 abs(X/Y)<=3e-6만 반사 평면에 맞춘 뒤
실제 정준 사분면의 면을 X/Y로 명시적으로 반사하였다. 이 정리에서 voxel 또는 CC를 다시 계산하지 않았다.

실제 렌더와 조형 판정
원본 3개 렌더를 재사용하고 후보를 같은 정면·몸체 사선·근접 사선 카메라로 렌더했다.
Blender 4.5.4 / 900x900 / 24 samples / flat shading / 저장 배열만 사용 / 렌더 중 형상 처리 없음.
원본과 마감의 카메라·재질·조명 조건 일치를 확인했다.
넓은 S자 주름과 뿌리 결속은 개선됐으나 표시한 말림 끝 일부는 아직 뒤엉키고 가장자리에 톱니가 남는다.
미세 디테일이나 자연스러운 말림의 해결이 완료됐다고 표현하지 않는다.
원본은 기준으로 보존하고 새 결과는 부분적 정리 효과가 있는 마감 후보로 별도 보존한다.
약간 두껍고 부드러워진 인상을 다음 수정의 기준으로 삼을지는 사용자 조형 판단을 받는다.
