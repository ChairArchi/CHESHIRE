CHESHIRE — 넓은 면 안쪽의 중간 접힘과 작은 골
2026-10-13 / Asia-Seoul

목표와 출발점
사용자가 승인한 다음 작업은 근접에서 구분되는 중간 접힘과 작은 골을 만드는 것이다.
최신 parent_linked_folds trial03의 실제 G7 XYZ를 직접 이어받는다.
이전 MIDDLE G7는 같은 ID와 위상 좌표를 제공하는 기준이며 형상 회귀 입력으로 사용하지 않는다.
MIDDLE 밀도와 큰 골, 넓은 면의 여백이 검토 기준이다.
이전 근접의 결손은 넓은 면과 말린 끝 사이의 중간 크기 구조 부족이었다.
테두리의 잔주름만 늘어나는 경우 중간 형상의 개선으로 판정하지 않는다.

고정한 단일 연산
MEDIUM: 기존 부모 위상의 양쪽 면에 넓은 mask를 적용하고 중간 능선과 골을 만든다.
SMALL: 실제 MEDIUM 결과의 법선을 다시 계산하여 그 흐름 안에 작은 골을 적용한다.
각 패스의 새 변위 벡터만 실제 quad 모서리 이웃 평균으로 2회 완화한 뒤 반사 ID로 운반한다.
본래 XYZ를 평균내지 않으며 두 패스 모두 현재 G7의 연결관계를 유지한다.
추가 CC 0회, 새 법선 형상장 2회, 새 변위 완화 4회이며 추가 topology event는 없다.
고정 PCHIP 높이 가중치, feature support, 실제 CC 위상 계보와 대칭 ID를 재사용한다.
고정된 부모 좌표를 따라 두 크기의 법선 방향 변위를 누적하는 방식이다.
실제 곡률 능선을 검출해 자라거나 스스로 topology 분기를 만드는 방식으로 설명하지 않는다.
구체적인 수치·정점 적용 비율·해시와 중간 좌표 복원 정보는 실제 generation.json에 기록한다.
최종 native 메시만 하나 저장하며 MEDIUM 중간 결과는 저장한 delta_medium으로 복원한다.

다공성에 관한 사용자 질문의 기술적 구분
사용자는 다공성 자체를 목표로 하지 않으며 이유가 없으면 적용하지 않는 편이 낫다고 밝혔다.
Digital Grotesque II 공식 설명에는 genus 전이, 여러 크기의 실제 구멍과 내외부 공간 연결이 명시되어 있다.
이 방식은 모래 binderjet 제작의 가능성을 활용한 확장된 topological subdivision이다.
Subdivided Columns의 어두운 부위를 모두 관통공으로 볼 수는 없다.
공식 설명의 핵심은 여러 크기의 subdivision이며 관련 논문에는 가중치 변경·법선 extrusion·정점 병합이 설명된다.
특정 사진의 빈 부분이 관통공인지 깊은 골의 음영인지에 대해서는 메시나 단면 없이 확정하지 않는다.
현재 작업은 연결관계를 유지한 표면 변형이며 Digital Grotesque II의 관통 구조 구현을 주장하지 않는다.
이번 목표는 골의 깊이와 접힘 크기의 관계이며 새로운 관통공을 만들지 않는다.

실제 검토 기준
전체 정면: 큰 골과 전체 실루엣, 넓은 면의 여백 유지.
본체 사선: 새 중간 골의 깊이가 단순 테두리 선보다 분명하게 읽힘.
근접 사선: 중간 접힘과 작은 홈의 폭·깊이 구분, 과도한 삼각 톱니 억제.
검사 통과는 조형 성공의 판정과 구분한다.
trial01 실제 저장·렌더 결과
본체 사선에서 넓은 면 안쪽의 S자 중간 골이 더 분명하게 생겼으며 하단 말림의 뿌리가 읽힌다.
전체 정면에서도 긴 세로 골이 늘어 변화가 보이며 테두리의 선만 증가한 결과는 아니다.
그러나 근접의 작은 조직은 독립적인 홈보다 중간 능선을 덮는 삼각형 면과 사선 톱니로 읽힌다.
기존 둥근 판과 말린 끝의 부드러운 덩어리감은 남으며 넓은 밝은 면의 여백이 줄었다.
중간 규모의 형상 진전은 확인하였으나 미세 마감과 여러 크기 위계의 완성은 확인하지 못하였다.
원본 trial03과 trial01의 실제 카메라·재질·PNG 조건 검증을 통과하였다.
실제 G7의 유한 좌표·폐합 유향 quad·단일 연결체·Euler 2·고아 정점 없음·양의 native 면적을 확인하였다.
실제 X/Y 반사 좌표 최대 오차는 모두 4.961703332445539e-14이며 유향 quad 대응도 일치하였다.
MEDIUM 최대 실제 변위는 0.0630150498039509, SMALL은 0.015183339900470274이다.
최대 합성 변위는 0.07763928966906139이며 원본 좌표계 단위이다.
MEDIUM 및 SMALL 적용 정점 비율은 84.22356448352597%, 59.26653007934461%이다.
이 비율은 완화 후 0이 아닌 control 변위의 비율이며 표면적이나 조형 성과 지표가 아니다.
원래 XYZ가 완전히 같은 정점 비율은 15.778377787051168%이다.
core checks의 symmetry_scope는 공통 저장기의 기존 미갱신 문구이며 실제 확인은 별도 symmetry 항목이다.
자기 교차·제작 적합성·전체 독립 replay·native triangle 집합 정렬은 수행하지 않았다.

필요한 마지막 변위 마감 trial02
중간 접힘의 깊이는 유지하면서 trial01에 나타난 삼각 톱니를 줄이는 후속 처리이다.
delta = trial01 XYZ - 실제 원본 trial03 XYZ만 이웃 평균 alpha 0.5로 3회 완화한다.
마지막에 실제 반사 ID로 변위를 운반하고 실제 원본 XYZ에 더한다.
원본 형상 자체를 평균내거나 변위 전체의 진폭 배율을 변경하지 않는다.
두 실제 입력과 코드·좌표 해시를 결속하며 같은 G7의 연결관계와 연관 배열을 유지한다.
원본 대비 형상장 2회는 trial01에서 계산한 계보 수치이고 이번 마감의 새 형상장 계산은 0회이다.
총 새 변위 완화는 trial01의 4회와 마지막 3회를 합한 7회이며 추가 CC는 0회이다.
이전 실행 코드와 원본 결과를 수정하지 않으며 최종 실제 메시를 별도 trial02에 저장한다.
trial02 실제 저장 결과
같은 G7의 유한 좌표·폐합 유향 quad·단일 연결체·Euler 2·고아 정점 없음·양의 native 면적 검사를 통과하였다.
실제 X/Y 반사 좌표 최대 오차는 모두 4.961703332445539e-14이며 유향 quad 대응도 일치하였다.
평균 전·후 최대 합성 변위는 각각 0.07763928966906139, 0.07703985939241494이다.
이 수치만으로 중간 골의 시각적 유지나 미세 마감 성공을 판정하지 않는다.
완화의 작은 영향 범위가 확장되어 원본과 완전히 같은 XYZ 정점은 6.88620608004954%이다.
이는 control 정점 비율이며 넓은 면이 사라졌다는 의미나 표면적 비율은 아니다.
실제 control 정점 7,002,114개와 quad 7,002,112개, native triangle 28,008,448개로 세대와 연결관계를 유지한다.
형상장 누적 5회는 선택된 whole_field 이후 계열의 기록 수치이며 프로젝트 전체 역사에서의 모든 변형 횟수가 아니다.
trial02 실제 렌더 판단
trial01의 넓고 깊은 중간 골과 하단 말림으로 이어지는 흐름이 유지되었다.
가장자리의 날카로운 돌기는 완화되었으나 중앙 사선 능선의 삼각형 면은 여전히 분명하다.
작은 골은 독립적인 깊은 접힘보다 중간 능선 위의 얕은 사선 조직으로 읽힌다.
원본 trial03보다 전체·본체 시점의 세로 구조가 명료해졌으며 근접에서도 중간 규모의 단면 변화가 확인된다.
원래 둥근 판과 말린 끝의 덩어리감은 남아 있고 넓은 밝은 면의 여백은 줄었다.
주 작업자와 독립 검토자가 실제 전체·본체·근접 비교판을 보고 같은 제한적 판정을 내렸다.
다음 개발을 위한 중간 접힘 체크포인트로 보존하며 근접 마감 완료나 최종 밀도 선택으로 취급하지 않는다.
사용자가 선택한 MIDDLE의 여백 기준은 계속 유지하며, 늘어난 밀도의 설계상 채택은 확정하지 않는다.
두 trial 모두 실제 메시·코드·native 배열·PNG 해시와 세 카메라·재질 조건 검증을 통과하였다.
부모 원본 PNG 3장을 재사용하고 각 trial의 실제 G7 PNG 3장을 새로 렌더하였다.
비교판의 원본 이미지를 자르거나 크기 변환하지 않았으며 smooth shading·modifier·normal map을 사용하지 않았다.
