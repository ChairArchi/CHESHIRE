판정
기존 기둥에 연결된 새 돌출부와 되돌아오는 말림을 생성하였다.
다만 변화가 작은 부착부에 집중되어 있으며, 근접 표면 전체의 개선으로 판정하지 않는다.
사용자는 전후 차이를 쉽게 구분하기 어렵다고 평가하였다. 이 피드백을 현재 시각적 성과의 한계로 기록한다.
기존 SPAN을 설계 기준으로 유지한다. trial01과 trial02는 연구 체크포인트이며 미적 개선안으로 확정하지 않는다.

구현
전체 높이에 분포한 8개 정규 주소를 X/Y 반사하여 32개 부모 접힘을 배치하였다.
기존 실제 면 패치를 작은 임시 닫힌 셸로 구성하고 Task32 sweep_disk로 연결 위상을 만들었다.
생성된 실제 부모 캡에서 자손 패치를 선택하였다. 11개 정규 자손이 수용되어 반사 후 44개 자손이 생성되었다.
정규 자손 제안 5개는 디스크 위상 또는 경계 조건 위반으로 거부되었다. 거부 기록은 보존하였다.
최종 연결 이벤트는 부모 32개 + 자손 44개 = 76개이다. 임시 뒷면과 칼라는 최종 메시에서 제외하였다.
원본 경계 정점 ID를 공유하며, 새 장식을 별도 부유 메시로 붙이지 않았다.
선택 패치 밖의 원본 위치와 면 슬롯, 원본 chart/rest/anchor 접두부를 보존하였다.
