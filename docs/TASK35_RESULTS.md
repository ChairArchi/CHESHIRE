# Task35 — 단일 기둥의 구간별 형상과 깊은 내부 접힘

최종 추천은 **H01_SHOULDER_GROWTH**, 단면 차이를 완화한 대안은 **H02_MILD_SHOULDERS**다. 긴 몸통은 넓은 8방향 부모 능선과 길이 방향의 팽창·접힘으로, 좁은 목은 4방향 능선의 결속과 그 내부의 하위 골로 발달했다. 수축부에서는 배열과 방향이 전환되고, 넓고 짧은 상부 구간에서는 능선이 다시 벌어졌다. 거친 단면에 세부 장식을 미리 넣지 않았으며, 중간·작은 골은 후속 연산에서 생성했다.

**기하학적 지역 분화와 깊은 내부 골은 확인했지만 전체 조형의 판정은 PARTIAL이다.** 두 후보 모두 추적한 물질 단면 47/47에서 작은 내부 골을 보였으나, 모든 부모 접힘의 깊이가 유지된 것은 아니다. 넓은 판과 긴 능선도 남았다. 실제 정면·측면 종단 절단에서는 마지막 단계의 작은 골이 충분히 추가되지 않았다. 기둥의 성과를 게이트 전체의 성공으로 확대하지 않는다. 상인방 제작·연결은 수행하지 않았다.

## 어떤 구간이 왜 다르게 발달했는가

초기 단면의 폭·깊이로부터 반경 대용량 `R=sqrt(half_width*half_depth)`와 기준 반경 대비 broadness를 계산했다. broadness는 초기 4/8방향 배열의 혼합을 바꾸고, 실제 수축·팽창 기울기와 단면 종횡비는 능선 방향을 바꾼다. 후속 단계에서는 실제 생성된 능선의 prominence·폭·chord 대비 높이와 길이 방향 팽창을 다시 읽는다. 같은 진폭을 부위별로 배분하는 것만으로 구성하지 않았다.

긴 판의 원인은 이 기둥 경로에서 더 구체적으로 확인했다. G0에는 이미 길고 평평한 다각형 면이 있다. F01은 마지막 angular 해상도만 절반으로 했다. 공통 정점의 최종 XYZ와 요청 변위 차이는 각각 약 `1.86e-10`이었다. 셀 크기를 줄였다고 변형 거리가 줄어들지는 않았다. F02는 형상 발생과 첫 접힘을 한 분할 단계 늦췄다. 공통 최초 형상 차이는 최대 0.00422, 최종 XYZ 차이는 최대 231.83/RMS 9.70이었다. 발생 시점·후속 source 판독의 영향은 있지만 넓은 판을 해소하지는 못했다. 이 실험이 발생과 첫 접힘의 모든 효과를 각각 분리한 것은 아니다.

## 새 규칙과 방향 수정

현재 XY 단면의 반폭·반깊이·반경·변화율·종횡비, 실제 native edge의 능선 prominence/폭, chord 대비 높이, 실제 생성된 길이 방향 팽창을 사용한다. full principal-curvature tensor나 임의 메시의 intrinsic chart를 구현한 것은 아니다. 계산되는 axial curvature는 진단용이며 최종 지역 규칙의 독립 결정변수로 사용하지 않았다.

초기 4/8방향 배열 뒤에, 검출한 부모 능선을 안쪽으로 접어 하위 능선을 만든다. 모든 거리는 물리적 프로젝트 단위와 실제 특징 규모를 기준으로 하며 current cell-edge 길이를 곱하지 않는다. 길이 방향 span은 실제 반경의 역수를 적분해 다시 읽고, 팽창부 재접힘은 Task34의 실제 axial feature 판독을 재사용한다. 양의 밀도 적분으로 단면 간격을 재배치하고 전체 높이·끝단을 유지한다. 각 단계의 데이터 판독은 이전에 생성된 형상에 반응하며, 세대 번호만으로 다른 장식을 지정하지 않는다.

강한 이중 골 분기가 항상 유리하다는 가설은 폐기했다. A04의 작은 골은 세계 단면 13/33, 물질 단면 23/47이었고, 같은 조건에서 이중 분기 혼합만 제거한 C04는 32/33 및 47/47이었다. chord 항 제거도 일부 골 분포를 늘렸다. 따라서 chord 보정이나 분기 수 증가를 단독 개선으로 선언하지 않는다. 결합군 E02→G01(분기 0.35)→G02(분기 0) 대조 후, 최종은 **부모 중앙을 접어 하위 능선을 발생시키는 간단한 조건**을 채택했다. 초기 배열·방향·길이 방향의 지역 반응은 유지한다. C05는 Task34 profile에 진폭만 지역적으로 배분하는 비교군으로, 새 profile의 순수한 한 항 제거 대조는 아니다.

V01은 G02를 명확한 중간 후보 ID로 보존한 결과다. V01의 작은 골이 없던 원래 Z=2725와 3062.5에서는 최종 radial 제어의 최소값이 둘 다 0이고 최대값은 103.58/145.76이었다. 안쪽 절개가 바깥쪽 성장과 더해지며 취소된 것이다. 이는 Task31의 과거 연산 순서나 Task33의 방향 결합 문제와 다른, **Task35의 성장·절개 중첩** 문제다.

H01/H02에서는 양의 성장을 절개 support 안에서 줄이고 부모의 옆면에서 유지한다. 음의 접힘을 임의 clip하거나 검사 기준을 바꾸지 않았다. 같은 V01 G7 직전 메시에서 한 연산만 바꾼 대조의 additive 재실행은 원래 최종 native SHA와 정확히 같았다. shoulders 조건에서는 위 두 위치의 안쪽 요청이 −67.09/−146.08로 회복됐고, 작은 골 물질 단면은 **41/47→47/47**이 됐다. 단일 단계 대조 표면의 전체 횡단 교차도 0이었다. 이 대조는 전체 생성 과정과 구분해 `diagnostics/G7_SAME_INPUT_COUPLING/`에 보존했다.

현재 형상 반응의 별도 인과 근거는 E08/E09다. 같은 producer 코드, 같은 입력·계수·분할이며 G0/G3/G4/G7 직전 native SHA가 모두 같다. 마지막 판독 source만 현재 생성 형상과 최초 형상 고정으로 다르다. 최종 XYZ 최대 차이는 235.34, RMS 18.48이며 두 결과 모두 전체 교차 0이다. broadness 차이 0.367, 기울기 차이 0.403, 길이 간격 제어 차이 32.63과 span phase 차이 1.016도 기록했다. A04/C06은 초기 producer 진단 필드 버전이 달라 보조 근거로만 사용했다.

## 변경 이유와 다음 연구

변경은 새 `task35_columns`와 독립 연구 도구·테스트·작은 레시피·현재 안내 문서에 한정했다. Task01–34 알고리즘·테스트·원본 연구 보고서는 수정하지 않았다. ALICE 환경은 Matplotlib을 읽기 전용으로 사용할 때만 참조했고 패키지 설치·수정은 하지 않았다. 새 외부 논문·구현 코드를 반입하지 않았다. 사용자 참고 이미지는 구간별 비례가 이후 생성에 영향을 줄 수 있다는 시각적 가설로 사용했으며, Hansmeyer의 정확한 알고리즘·물리적 buckling·특정 작품 재현을 주장하지 않는다. 프랙탈을 설계 논리로 도입하지 않았다. 라이브러리 버전·라이선스 metadata와 DLL SHA는 최종 테스트 기록에 있다.

기술적으로 선택한 대안은 세 가지다. 게이트의 높이 대응 복사를 기둥의 X/Y 반사로 교정했고, 강한 이중 분기보다 부모 중앙 접힘을 채택했으며, 양의 성장과 절개가 같은 위치에서 취소되지 않도록 support를 분리했다. 각각 이식 실패, 단일 제어 대조, 같은 직전 메시 대조와 전체 재생성으로 검증했다. 형상을 평균화해 대칭을 맞추거나 알고리즘을 큰 범용 시스템으로 확장하지 않았다.

다음 연구는 H01/H02를 단순히 더 분할하는 것보다, **정면·측면 종단에서 새 하위 골이 없는 부모의 넓은 옆면**을 작은 진단 조각으로 분리하는 것이 우선이다. 현재 특징 판독은 단면 능선과 둘레 최대값의 길이 profile에 집중하므로 넓은 면 내부의 다음 접힘을 충분히 선택하지 못한다는 가설이 남는다. 512 판독 표본과 scalar sigma=0.035의 영향, 작은 골이 처음 나타나는 시점의 국소 clearance, 하위 접힘의 길이 방향 연결을 분리해 확인해야 한다. 전역 tensor solver나 게이트 결합을 먼저 만드는 것은 이번 성과의 직접적인 다음 단계가 아니다.

후속 연결 연구에는 검증된 끝단 좌표·방향과 생성 의존 조건을 사용할 수 있다. 연결부를 실제로 자르거나 상인방을 결합할 때에는 새로운 토폴로지·횡단 검증이 필요하다. 최종 미적 선택과 작품의 개념은 사용자가 결정한다.
