# CHESHIRE 기둥 디테일 발달 비교

**부분 채택: 작은 연속 되접힘은 유효하지만, 단순 반복이나 돌출 증폭만으로 작은 스케일의 장식 위계가 확보되지는 않았다.** 큰 형태의 기준안은 OVERLAP G3로 유지한다. RETURN_DETAIL G4는 국소 접힘 자산으로 보존하며, 이번 결과가 기준안을 대체할 만큼 개선되었다고 판단하지 않는다.

## 실제 형상 비교

[정면·사선·측면 전체 비교](images/whole_comparison.png) · [같은 위치와 배율의 확대 비교](images/detail_comparison.png) · [되접힘과 후속 형상장 비교](images/return_progression.png) · [E/F 증폭 비교](images/nested_progression.png)

모든 이미지는 저장된 실제 삼각형 메시의 렌더다. 동일 뷰의 카메라·재질·조명을 유지했으며 별도 표면 텍스처나 기하학적 smoothing은 사용하지 않았다. 확대 뷰는 전 후보에 같은 좌표와 배율을 적용했다.

| 시험안 | 실제로 달라진 것 | 조형 판단 |
|---|---|---|
| CONTINUED G4 | 기존 Task36 subdivision + Mandelbrot 계열 형상장 1회 추가 | 큰 골은 남지만 격자와 얇은 crust 증가가 주효하다. 반복 중단. |
| NESTED G4 | 큰 골 주변에만 E/F 방향 normal relief | 큰 접힘 보존에는 유리하지만 새 접힘은 너무 약하다. |
| NESTED_STRONG G4 | 같은 영역의 E/F 계수를 3배 증폭 | 깊이는 생기지만 셀별 별·가시로 읽힌다. 크기만 키우는 해법은 비추천. |
| RETURN_DETAIL G4 | 기존 radial/axial PCHIP 연산으로 작은 되접힘 2곳 추가 | 상부 정면의 대향 lip과 하부 측면의 접힌 테두리가 생긴다. 가장 유효한 국소 변화다. 끝이 얇고 찢긴 듯한 인상은 남는다. |
| RETURN_HYBRID G4 | RETURN_DETAIL의 동일 저장 상태에 형상장만 1회 추가 | 작은 되접힘은 남지만 기존 중앙 chevron이 약해지고 넓은 패널이 강해진다. 전체 개선으로 평가하지 않는다. |

새 안은 모두 G4에서 멈췄다. 각각 409,600 triangles로 기준 G3의 4배지만, 면 수 증가는 조형 성과와 별개다. RETURN_DETAIL의 전체 실루엣 변화도 작다. 이번 성과는 서로 다른 규모의 접힘이 일부 영역에서 공존한 것이며, 전체 기둥의 자동 장식 발달을 해결한 것은 아니다.

## 기술 판단과 남은 병목

IAAC가 subdivision과 Mandelbrot를 함께 사용한다는 점은 공개 자료에 명시되어 있다. 현재 CHESHIRE의 결합 경로도 두 연산을 사용한다. 다만 정확한 원본 3D 수식·가중치를 회수한 재현이라고 주장하지 않는다. no-field 가지는 연산의 효과를 분리해 보는 비교군이다. [공개 자료 해석](SOURCE_NOTES.md), [제공 논문 검토](PAPER_NOTES.md).

작은 되접힘이 후속 형상장에서도 남았지만, 되접힘 활성 정점 4,868개 중 형상장이 움직인 것은 658개뿐이다. 이를 일반적인 crease memory 확보로 해석할 수 없다. 기존 보호 마스크도 최대 약 95% 감쇠이며 완전 고정 정점은 0개다. 오래된 접힘을 모든 연산에서 일관되게 보호하는 규칙은 아직 없다.

또한 기존 정점을 고정해도 비평면 quad의 mean-fan 재분할로 실제 표면이 조금 달라진다. 측정한 child-centre 편차의 중앙값 .000432는 약한 NESTED 변위의 중앙값 .000716과 같은 규모다. 따라서 아주 작은 시각적 차이를 전부 새 주름의 성과로 볼 수 없다. 수치는 모델 단위이며 제작 해상도나 최소 장식 크기를 의미하지 않는다.

## 핵심 검증

RETURN_DETAIL과 RETURN_HYBRID의 실제 float64 렌더 메시에서 확인했다.

- X/Y 반사 정점 대응과 삼각형 집합 일치, 최대 오차 `<5.36e-15`.
- 연결체 1개, boundary/nonmanifold edge 0, 폐합 및 winding 일관성 확인.
- **두 안 모두 자기교차 확인.** 첫 교차 증거 검출이며 교차 총량 비교는 아니다. 원본 G3에도 교차가 있다.
- 나머지 세 약한 안은 빠른 메시·렌더 검사까지만 시행했으며 자기교차는 미검증이다.
- 두께·구조 성능·제작 가능성은 전부 미검증이다. 원본, 실패안, 검사 기준을 보존했다.

[핵심 검사 원기록](technical/core_validation.json) · [실제 파일 위치](INDEX.json). 생성 당시 JSON의 미검증 표시는 보존했으며 이후 core 검사 기록이 최신 상태다.

## 다음 단계

계속할 때는 두 항목으로 범위를 좁히는 것이 낫다.

1. 동일한 셀 돌출 반복 대신 기존 지역별·세대별 subdivision 가중치를 이용해 큰 골, 어깨, 내부 면에 서로 다른 발달 규칙을 준다.
2. 기존 접힘 보호를 subdivision과 형상장 양쪽에 연결하고, 재분할 표면 변화와 새 접힘의 효과를 구분한다.

Tissue/frame_bundle은 별도 자산으로 보존했다. 이번에는 적용하지 않았다. 분리된 기둥·상인방 게이트도 아직 적용 가능성에 관한 가설이며, 게이트 형상 시험은 진행하지 않았다.
