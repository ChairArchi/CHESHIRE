CHESHIRE — 실제 공유 경계에서 새 접힘을 만드는 실험
2026-10-12

가설

기존 큰 면과 연결 구조를 보존한 채 미세 변위를 누적하는 조건이 큰→중간→작은
접힘 관계의 발달을 제한했다. 기존 WALL G3의 넓은 어깨를 여러 면이 연결된 패치로
선택하고 실제 공유 경계에서 옆면·cap을 생성하면, 작은 요철을 더하는 방식과 다른
입체 관계를 만들 수 있다. 새 cap의 실제 형상에서 후손 패치를 선택한다.
성공은 미검증이다. 과거 Task32의 블록 같은 cap과 넓은 전이 면 실패도 비교 근거다.

변경하는 비교 조건

기존 G6 마무리와 큰 다각형 면의 정확한 좌표를 보존하는 조건을 풀고 G3로 돌아간다.
기존 .04 또는 .65 변위 상한을 이번 생성 연산자의 설계 조건으로 사용하지 않는다.
패치의 실제 면적·형상 범위에 따른 비율을 사용한다. 세분에서 실제 CC 평균화를 허용한다.
면 연결 구조가 바뀌며 내부 차트는 더 이상 일대일 표면 매개화로 간주하지 않는다.
이전 성공 기둥과 게이트, 원본 연구 코드·체크포인트는 변경하지 않는다.

유지하는 목표

실제 본체 경계에서 이어지는 한 개의 닫힌 몸체, X/Y 반사 대칭, 두 입력의 같은 규칙.
자기교차는 이번 탐색에서 제거하거나 합격의 선결 조건으로 삼지 않는다.
같은 카메라·재질의 실제 메시를 비교하고 기술 PASS와 조형 판정을 분리한다.
큰 출력은 E:\CHESHIRE_DATA\experiments\connected_fold_growth_20261012에 저장한다.

대안과 계보

SMOOTH_CONTROL: 기존 WALL G3에 중립 CC 세분 두 번.
ROOT_ONLY: G3의 긴 공유 경계 패치에 실제 ring·sidewall·cap 생성 후 중립 CC 두 번.
BRANCHED: 같은 root의 실제 cap에서 작은 후손과 그 다음 후손을 선택·생성 후 중립 CC 두 번.

세 대안의 최종 세분 단계는 모두 G5다. 공유 경계 sweep은 G를 증가시키지 않는다.
G3의 constructive event 횟수, 반사된 전체 event instance 수, 실제 CC 횟수를 분리한다.
원본 WALL G3의 native 표면은 VF이며 이 시험의 새 표면은 명시적인 mean quad-centre
fan으로 해석한다. SMOOTH_CONTROL의 G3 control 좌표 보존을 원본 VF physical 표면의
정확한 보존으로 설명하지 않는다. 세 대안의 G5에서는 같은 mean 해석을 사용한다.
기존 Task32 sweep_disk와 교정된 reference_subdivision의 neutral CC를 재사용한다.
새로운 Hansmeyer 알고리즘 복원이나 새로운 Mandelbulb 형상장으로 표현하지 않는다.

판정

원래 어깨에서 갈라지는 방향과 빈 공간이 중거리에서도 읽히는가.
작은 형상을 부모의 실제 옆면·끝·골에서 추적할 수 있는가.
두 입력이 같은 장식 모듈로 수렴하지 않으면서 같은 관계를 만드는가.
박스 cap, 별형 반복, 가시, 과도한 소형 면 분절이면 해당 방향을 성공으로 평가하지 않는다.
후손이 실제로 생성되지 않았으면 요청한 수와 실제 수를 분리하고 거절 이유를 보존한다.
