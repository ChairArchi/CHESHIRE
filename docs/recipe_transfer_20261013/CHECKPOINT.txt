결론

현재 SPAN 기둥의 디자인 언어와 선택 연산을 유지한 채, 초기 반경 프로필만 바꾼
WAIST_FULL 기둥 하나를 G0부터 최종 G7까지 실제 생성하였다.
새 기둥에 맞춰 중간 계수·활성 창·형상장·디테일 규칙을 재조정하지 않았다.
단일 생성 명령에서 15개 상태를 이어 계산하여 기존에 분리돼 있던 실행 경로를 연결하였다.
최종 제어 메시와 실제 native는 저장 검사와 실제 XYZ/유향 quad 대칭 검사를 통과하였다.
같은 정렬의 parametric seed 계열에서 제한적인 레시피 전이를 확인한 결과이다.
임의 단면·비대칭 형상·독립된 새 메시까지 자동 처리하는 범용 생성기라는 뜻은 아니다.

입력에서 바꾼 것

기존 조정된 SPAN_SPARSE recipe의 radius knot 8개에 다음 배율만 적용하였다.
[1.00, .82, .88, 1.20, 1.16, 1.02, .86, 1.00]
허리 반경을 키우고 상하의 팽창부 반경을 줄이는 비례 변화이다.
G0의 event·축방향 warp·25-ring/16-sector carrier·chart·topology는 유지하였다.
실제 G0 control/chart/faces 대조에서 recipe 변경 key는 radius 하나였다.
G0의 최대 실제 control 이동은 .15734826388888914 원본 메시 단위이다.
INPUT_ONLY_VERIFICATION.json에 원래/새 반경과 동일 조건 대조를 보존한다.

그대로 적용한 선택 순서

G0_INPUT → G1_ANCESTRY → G2_OVERLAP → G3_WALL → G3_ROOT → G3_SIDEWALL
→ G4_NEUTRAL → G5_DIRECTIONAL → G6_DEPTH08 → G6_MIDDLE → G7_SURFACE
→ G7_LINKED_RAW → G7_LINKED_FINISHED → G7_WIDE_RAW → G7_FINAL.

G1/G2의 Task36 recipe, finite field4/8, fraction .55, budget .35/.28,
G2의 두 PCHIP return, G3의 측정 벽과 root/sidewall 규칙은 원본 조건과 일치한다.
후반 DIRECTIONAL·DEPTH_08·MIDDLE·connected_ribs V2·WIDE_ROOT recipe도 일치한다.
두 변위 마감은 각각 기존의 이웃 평균 alpha .5를 3회 적용하였다.
전역 FINE과 G7 Mandelbulb 마감은 이 선택 경로에 추가하지 않았다.

새 입력에서 다시 계산한 것

실제 법선·edge scale·root의 PCA와 반경·선택 패치·event 후손·대칭 ID를 새로 계산했다.
새 MIDDLE G6의 위상·높이·support를 실제 새 CC의 V/E/F 대응으로 G7에 운반했다.
기존 SPAN의 G7 XYZ나 위상·PCA 배열을 새 기둥에 주입하지 않았다.
새 G5의 실제 방향장 파장은 .2929080622424133이며 원래는 .30178309181397694이다.
이는 같은 .70R 규칙이 새 root 크기에 반응한 결과이며 계수를 조정한 것이 아니다.
root 1개와 sidewall child 3개가 기존 선택 규칙으로 생성되었다.

실행 경로

experiments/recipe_transfer_20261013/run.py가 초기 단계와 후반 단계를 순차 실행한다.
early.py는 원본 frozen 함수로 G0~G4를 계산하고 역할·event·반사·parent 정보를 전달한다.
late.py는 원본 build 함수로 G5~G7와 같은 세대의 추가 변형을 연결한다.
밀집 배열의 메모리를 반환하기 위해 단계별 Python subprocess를 직렬로 실행한다.
이 구조는 단계 사이에 수작업으로 형태를 수정하거나 새 계수를 선택하는 것을 뜻하지 않는다.
현재 입력 정의는 WAIST_FULL 한 사례로 고정돼 있다. 다음 입력을 지정하는 인터페이스의
확장은 가능하지만 이번 결과를 다양한 임의 입력의 완료된 도구로 설명하지 않는다.

재현 명령

C:/Users/USER/CHESHIRE/.venv/Scripts/python.exe -X utf8 -B -u
  experiments/recipe_transfer_20261013/run.py --root <새 E 드라이브 출력 폴더>

이 명령은 같은 WAIST_FULL 사례를 생성한다. 기존 출력 폴더는 덮어쓰지 않는다.
--resume은 같은 코드로 완료된 초기 구간과 후반 저장 단계에서 이어갈 때만 사용한다.
초기 구간 도중 중단된 부분 실행을 자동으로 복구하는 기능은 없다.
실제 이번 전체 생성 시간은 656.859초, 약 11분이었다. 향후 모든 입력의 소요시간 보장은 아니다.

실제 시각 판독

긴 세로 주름, 말린 잎 끝, 팽창과 결속의 리듬이 두 기둥에 공통으로 남는다.
새 기둥은 허리와 중간 줄기가 조금 더 충실하고 골 묶음의 간격·휘어짐이 달라진다.
본체 사선에서는 하단 말림과 주름의 진행 경로 변화도 보인다.
전체 정면의 큰 배치는 비슷하다. 강하게 다른 캐릭터보다 가까운 형제 배리에이션이다.

근접의 삼각 면·사선 지퍼 조직·둥근 판과 작은 골의 위계 부족은 남아 있다.
이번 결과를 근접 디테일 품질 개선이나 새 형상의 미적 우월성으로 판단하지 않는다.
주 작업자와 독립 검토자가 실제 보드 5개를 보고 같은 조형 계열 유지로 판독하였다.
사용자가 새 배리에이션을 최종 설계로 채택한 것은 아니다.
