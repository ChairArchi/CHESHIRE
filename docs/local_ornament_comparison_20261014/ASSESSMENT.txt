CHESHIRE — 국소 입체 장식 비교 / 2026-10-14

상태
두 후보의 실제 생성과 동일 조건 비교를 완료하였다. 두 후보 모두 원본의
어색한 끝부분을 해결한 최종안으로 채택하지 않는다. 활성 설계 기준은 변경
없는 WIDE_ROOT_FINISHED / SPAN / G07이다.

공통 조건
사용자가 표시한 대각선 띠의 실제 원본 표면에서 정규 영역 6개 뿌리를 고르고,
X/Y 반사로 각 후보에 24개를 배치하였다. 최대 뿌리 상대 반경은 0.038943369,
법선 방향 전체 높이는 0.058415054이다. 높이의 22% 지점에서 실제 장식 내부
점을 원본 표면 정점에 일치시켰다. 국소 중첩은 확인하였으며 용접·Boolean
융합·접선 연속성·충분한 접합 두께를 확인한 것은 아니다.

A — 실제 입체 Mandelbulb
power8 / 유한 10회 계산 / 193³ 표본 / 연속 escape-count 등위면9.5이다.
예전의 높이 atlas와 다른 실제 3차원 닫힌 표면을 사용하였다. 가장 큰 연결
성분만 남겼고 평활화하지 않았다. 배치 시 두 후보의 외곽 범위를 맞추기 위한
XY/Z 비등방 배율을 적용하였다. 무한 프랙탈의 정확한 경계나 SDF는 아니다.

근접 렌더에서는 네 군집이 작은 꽃송이·버튼처럼 분명하게 보이고, 일부 군집은
기존 면에 가려진다. 군집 안의 더 작은 돌기 위계가 드러나는 점은 확보하였다.
다만 긴 주름에서 성장한 끝보다 별도로 붙인 덩어리에 가깝다. 기존의 잘린 컵
모양과 얇은 판의 불규칙한 중첩은 그대로 남아 있다.

B — 제어된 작은 잎 군집
닫힌 잎 3개를 공통 뿌리에서 중첩하였다. 중앙 능선, 가장자리 굽음, 짧은 끝
말림을 실제 메시로 생성하였다. 기존 얇은 잎·판의 조형 언어에는 A보다 가깝다.
그러나 이 카메라에서 잎맥과 작은 말림의 위계는 분명하지 않다. 일부 끝은
추가된 얇은 파편으로 읽히며, 본체 면에 묻혀 변화가 작은 부분도 있다.

확보한 점과 남은 문제
원본을 바꾸지 않고 실제 3D 미세 장식을 대칭으로 추가하고, 뿌리를 중첩시켜
보존·비교하는 경로는 확보하였다. 전체 기둥의 큰 흐름은 두 후보 모두 유지된다.
그러나 원래 끝의 어색함을 정리하거나 자연스럽게 이어지는 근접 디테일을
확보하였다고 판단하지 않는다. 같은 반경과 높이는 같은 부피·투영면적·시각적
밀도를 뜻하지 않는다. 얇은 B는 A보다 가려지기 쉽다.

다음 기술 과제
장식 생성 방법보다 기존 끝과 장식 밑동의 관계가 병목이다. 선택한 형태 언어로
대표 끝 하나의 실제 크기와 접선 방향을 얻고, 그 끝에 맞춰 밑동과 발달 방향을
맞추는 좁은 수정이 적합하다. 군집 수 증대나 전체 평활화는 근거가 부족하다.
이번 시험에서는 추가 후보·추가 세대·원본 끝 교체를 실행하지 않았다.

디자이너 판단
A의 미세 군집 언어를 도입할지, B의 잎·주름 언어를 유지할지 질문하였다.
답변 전에 어떤 후보도 채택하거나 그 선택에 의존하는 후속 형상을 만들지 않는다.

검증과 한계
원본 파일 해시와 실제 선택 좌표의 동일성을 확인하였다. 두 프로토타입의 닫힘,
면 방향, 연결 성분, 양의 면적 등을 생성 시 확인하였다. 추가 메시의 구성상
X/Y 반사 대응 잔차는 정확히0이다. 원본 본체는 Blender에서 한 번만 불러와
두 후보 렌더 후 실제 좌표와 삼각형 인덱스 해시가 같음을 확인하였다.
원본3장+후보6장의 카메라·재질·조명·표본 조건을 검증하였다.
실제 Boolean 융합, 전체 자기교차 해소, 제작 가능성은 검증 범위가 아니다.
Mandelbulb에는 매우 작은 marching-cubes 삼각형이 있으며 최소 양의 면적이
렌더용 float32 정밀도의 모든 삼각형 비퇴화를 보장하지는 않는다.
