CHESHIRE 수렴 문제 연구 정리 / 2026-10-11

현재 결론
큰 접힘이 초기에 약해지는 경로와, 후기 잔돌출이 작아지는 경로를 분리했다. 첫 번째는 기존 배치 가중치의 역산으로 G5까지 개선할 수 있었다. 두 번째는 후기 법선 요청량에 반응했다. 그러나 새 분기가 세대마다 발생하고 서로 다른 마디가 얽히는 목표는 아직 해결되지 않았다. 다음 단계의 기준은 돌출이 더 거칠어지는지가 아니라, 큰 구조를 유지하면서 새 위치·방향의 형상이 생기는지다.

자기교차 억제 가설은 사용자가 종료한 상태다. 이번 연구에서 재개하지 않았다. 기존 엔진과 성공한 게이트·Tissue·G7/G8 체크포인트를 수정하지 않았다. 모든 생성 비교는 별도 outputs 폴더에서 실행했다.

핵심 실험과 판단

1. 초기 입력과 마디
같은 64 quad 입력에서 기단의 초기 되접힘만 달리하면 G5까지 단면 중첩이 남았다. 컵형 중첩이 새로운 가지를 자동으로 만든 것은 아니다.
규칙적인 네 돌기 입력은 기단의 방향성에 다른 결과를 남겼다. 7개의 직선 몸통 고리를 추가한14마디 입력은 처음 표면 자체가 같다는 것을 확인한 대조다. 더 많은 마디만으로 서로 다른 모듈이 생기지는 않았다.
그 뒤14마디 입력에 세 곳의 되접힘을 추가하고, 마디별 CC/DS 매개변수까지2x2로 비교했다. G4의 큰 굴곡은 달라졌지만 새 계층적 분기와 구획 간 얽힘은 충분하지 않았다. 규칙적인 네 방향 조직은 계속 유지했다.

2. 첫 분할에서 얼마나 약해지는가
초기 되접힘 꼭짓점48개, tip/neck24쌍의 실제 source-corner 구성 계보를 추적했다. 첫CC 뒤24쌍 모두 높이 역전 방향은 남았다. 하지만 높이차/초기 높이차의 중앙값은0.1122였다. 법선 항을 제거하면0.0819로 더 낮아졌다. 이 입력에서 첫 약화는 법선 돌출보다 배치의 영향이 크다.
선택한48개 corner 잠금은 첫 단계에 높이차1.0을 보존했다. 이것은G1 진단이며, DS를 포함한 지속 잠금 구현이나G8 검증이 아니다.
초기 source-ring 집단 평균Z의 역전 수와 실제corner 계보 쌍의 역전 수는 다른 지표다. 전자의 감소를 모든 되접힘이 첫 단계에 사라진 것으로 해석하면 안 된다.

3. 역할값 평균 계승이 주원인인가
같은 해석 함수를 계승된 재료 좌표에서 매 세대 다시 계산한 조건을, 값 자체를 양의 가중치로 계승한 조건과 비교했다. G0–G2 좌표는 반올림 오차 이내 동일했다. G4 평균 점 차이0.000692, 최대0.06962로 큰 형태는 유사했다. 이번 역할 함수를 재계산하는 것만으로 해결된다는 근거는 약했다. 이것은 현재 물리적 XYZ에 적용하는3D 영향장과 다른 실험이다.

4. 기존 CC/DS 배치 가중치의 역산
CC corner의 기존 w2, DS face-corner의 기존 w1만 분할 전에 정했다. CC는Z(w2)=B+w2D에서 원 corner 높이를 목표로 했고, DS는 같은 면의 corner 높이 오차 제곱합을 최소화했다. CC 목표값은[-8,8],DS는[-1.5,.90]로 제한했다. DS상한.90은 평행사변형에서 정확한 보간으로 인한 붕괴를 피하려는 이번 실험의 선택이다.
source-u 몸통 범위에서만 완만하게 활성화했다. 법선의 부호 있는 이동 요청 길이는 공통 고정 필드를 그대로 사용했다. 실제 법선 방향은 각 조건의 현재 형상에 따라 달라진다. 출력 좌표 복원·corner 잠금·추가 변위·위상 결합은 없었다. 이 축방향 제어는 CHESHIRE의 기둥 실험이며 원 저자의 수치 레시피를 복원한 것이 아니다.

G5 추적24쌍 높이차/초기 높이차 중앙값:
  기존 배치                  −0.0633   역전 방향8/24
  보존 강도0.5                0.3470   역전 방향24/24
  CC만 보존                   0.5408   역전 방향24/24
  DS만 보존                   0.0721   역전 방향20/24
  CC와DS 모두 보존             1.0060   역전 방향24/24

같은 카메라 실제 메시 렌더에서도 들린 끝과 골의 차이가 남았다. 첫CC의 큰 초기 약화와 이후DS의 추가 약화를 둘 다 다뤄야 했다. 위 수치는24쌍의 계보 평균 높이차이며 전체 표면 보존율이 아니다.
G5는122,882 vertices /122,880 faces다. 유한 좌표, 닫힌 메시, 일관된 winding,1 component, 양의 팬 삼각형 면적을 확인했다. 이것은 자기교차 없음의 증명은 아니다.

5. 같은 제어를3D 오차 기준으로 바꾸면 더 나은가
같은 scalar 가중치·범위·support에서 높이만이 아니라XYZ 배치 오차 제곱합을 최소화했다. G5 높이차 비율1.0261, 초기12개 주돌기 쌍의 투영 반경 차이 비율0.8683이었다. 축방향만 쓴 경우1.0060 /0.8194였다. 조금 나아졌지만 실제렌더의 큰 구조는 유사했다. 기준 축 변경만으로 새 분기가 생긴다는 근거는 약했다. 이 역시 전체표면의 반경 보존율이 아니다.

6. 기존 Eq10/11은 도움이 되는가
기존 sharp_subdivision의 literal 식을 재사용했다. 새 면·모서리 점을 초기 tip역할+1,neck역할−1에 따라 이동시킨다. 합은 원 수식대로 정규화하지 않았다. w6/w7 각각0/.2의2x2 비교와, 큰 접힘 보존과의 조합까지 검토했다.
국소 접힘과 겹침은 달라졌지만 이번 설정으로 큰 분기 다양성이 충분히 늘지 않았다. G5의 주돌기 쌍 투영 반경 차이는 보존만0.8194, 조합0.6582로 오히려 감소했다. 모든 Eq10/11 설정에 대한 부정 결론은 아니다.
공통 법선 요청은 같지만 Eq10/11이 더하는 벡터에도 법선 성분이 있으므로 최종 총 법선 이동 성분이 같다고 주장하지 않는다.

7. 후기 잔돌출은 무엇에 반응하는가
완전히 같은 보존G4 메시에서G5 한 단계만2x2로 비교했다: 몸통 법선 요청1배/4배,현재 Eq4활성/끄기. 다른 배치 가중치와 연결은 같다.
몸통 법선 요청을4배로 키우면 작은 돌출이 더 남았다. 정면 고정 몸통ROI 실루엣 면적은50,085→50,684 pixels,약+1.20%였다. 외곽 큰 구조의 변화는 작고, 내부의 국소 돌출 변화가 더 눈에 띈다. 이 결과를 새 분기 다양성의 해결로 해석하지 않는다.
Eq4를 끄면 더 매끈해졌다. 면점 외 좌표는 정확히 같았다. 이번 Eq4는 디테일을 만드는 데 기여하므로 약화의 주범이라고 볼 근거가 없다.
법선 변경에 의한 좌표차를 공통 입력 법선으로 예측한 최대오차1.77e−15,2x2 좌표 가산성 최대오차1.78e−15였다. 요인들이 의도한 경로로만 바뀐 것을 확인했다.
실루엣은 백색 emission 재질의 실제 메시를 같은 카메라로 렌더했다. 정면/사시 shaded6장, 실루엣10장의 메시 SHA 대응을 확인했다. 실루엣의 픽셀 경계 수는 분기 수·기하학적 다양성 점수가 아니다.

자료에서 가져올 것

Hansmeyer의 Design by Subdivision은 세대별·공간별 가중치, 위상 모티프, 실제 quad 평면성, 그룹 잠금과 공간 영향장을 설명한다. Figure9는8세대 뒤 locking을 사용했다고 적지만, 잠금 대조 실험이나 원 수치 레시피를 제공하지는 않는다.
https://archive.bridgesmathart.org/2010/bridges2010-167.pdf

From Mesh to Ornament의 differentiated input은 주두·기단과 서로 다른 모티프를 갖는다. 동시에 이 장은 input cell별로 장식이 제한돼 반복 부품처럼 보일 수 있다는 한계도 지적한다. 따라서 초기 형상 차이는 필요할 수 있지만, 부위 구분만 늘리는 것은 현재 병목의 해답이 아니다. 근접 정점 결합으로 모티프가 달라지는 설명은 단순 자기교차나 초기 중첩과 별개의 위상 변화다.
https://ecaade.org/current/wp-content/uploads/2022/03/eCAADe_2010.pdf#page=286

IAAC Mesh Subdivision은 현재 좌표 조건을 반복 평가하고 여러3D 영향 범위·교차 곡선을 이용하는 아이디어를 준다. Mandelbrot 자체로 갈아탈 필요는 없다. 검토한 페이지에서 원 .py/.gh 소스 링크를 확보하지 못했으므로 도식에서 읽은 흐름을 정확한 코드로 오인하지 않는다. DragonSkin도 범위·offset·attractor를 분리한 비교의 참고지만 지속적인 위계 보존의 증거는 아니다.
https://www.iaacblog.com/programs/mesh-subdivision/
https://www.iaacblog.com/programs/dragonskin-python-for-grasshopper-mesh-subdivision/

현재 코드의 높이장은 이미 매 세대 현재 정규화Z를 평가한다. 없는 기능을 있다고 새로 만들 것이 아니라, 다음 영향장과의 차이는3D 범위, 방향, 서로 다른 부위에 걸치는 지원 영역이어야 한다.
ATLV의 실제 교육 코드 일부도 읽었다. 단순 quad 분할은 기존 정점을 유지하는 점에서 CC 평균 배치와 다르다. 예시의 예쁜 결과를 그대로 같은 알고리즘의 근거로 쓸 수 없다. 방향 벡터를 scale한 뒤 unitize하는 부분은 범위 내 크기 감쇠가 없어지는 점도 확인했다.
https://atlv.org/education/ghpython/

다중해상도 기하 잔차와 crease는 큰 형태를 보존하는 다른 근거다. 기존 CHESHIRE에는 실제 자식 edge를 추적하는 crease 및 Mola/Tissue 자산이 이미 있으므로 재구현하지 않는다. mixedDS의 crease/잠금/잔차 대응은 별도 정의가 필요하다. OpenSubdiv/GPU는 계산 가속의 수단이며 모듈 다양성 해결 자체는 아니다.
https://www.multires.caltech.edu/pubs/irrsub.pdf
https://www.opensubdiv.org/docs/subdivision_surfaces.html

실제 평면성 지표 진단
논문의 fourth-corner 평면거리/나머지3점 둘레를 기존 메시에서 계산했다. 순서 민감도를 피하려4개 순환 선택의 최댓값을 쓴 것은 이번 진단의 선택이다. 보존G4에서 vertex incident평균과 기존 법선 변화 proxy의 Spearman상관은0.258이었다. 서로 동일한 조건이 아니며 기존 proxy 실험의 약한 결과를 논문의 평면성 조건 실패로 일반화하면 안 된다. 아직 생성 가중치에 적용한 인과 비교는 하지 않았다.

다음 수정 후보 두 가지
1. 현재의 큰 접힘 보존을 유지하고, 후기 세부 생성은 실제 quad 평면성·feature/scale 조건으로 나눠 증폭한다. 일괄4배보다 역할별 부호와 범위를 조절해 기존 큰 구조 위에 다른 위치·방향의 세부가 생기는지 비교한다. 기존 normal-variation proxy와 원 평면성 조건을 대조한다.
2. 인접 마디를 함께 가로지르는 작은3D 영향장을 도입한다. 네 방향 규칙성은 유지하되 현재 형상에서 영향과 방향을 재평가한다. 같은 마디의 잔돌기 강화와 마디 사이 새로운 돌출·겹침을 별도로 판단한다. 이 방향장은 아직 생성 실험하지 않았다.

보존 및 재현 범위
preservation_audit.json은 기존 아카이브의13개 선택 파일과 현재 파일의 SHA256 일치를 확인했다. 여기에는 원 성공 게이트 상태, 실제 wide Tissue,frame bundle,G7/G8 메시와 주요 코어/실행 코드가 포함된다. 전체 아카이브를 새로 재검증했다는 뜻은 아니며 인수인계에 명시된 과거 source-hash 예외는 그대로 남는다. git tracked diff는 없다.
각 신규 실험에는 manifest,코드,checkpoint,operator_metadata,validation,고정 카메라 렌더와 원본 메시 SHA기록이 있다. EXPERIMENT_INDEX.json은13개 비교 그룹의 실제 파일을 연결한다. SOURCES.json은21개 출처의 검토 깊이와 도입 가능성, HYPOTHESES.json은25개 가설의 상태를 담는다.
이번 신규 비교는G5까지다. 이 결과를 아직G7/G8 또는 게이트 전체에 일반화하지 않는다. 생성 계산은CPU에서 수행했으며GPU 생성 이식이 완료됐다고 주장하지 않는다.
