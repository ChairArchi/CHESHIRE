  한계: 초기 Task01–05 개별 실행 기록 일부 부재. 일반 프로그램 완성 판정과 별개.

2. 통합 검증이 필요한 조합
B01 기존 큰 접힘 + Tissue의 전면/후면·접합 완성
  이미 완료: 기존 microfold/section TARGET 위의 연속 조직 적용은 실제로 완료.
  미검증: 전체 뒷면까지의 조직 범위와 원본 게이트에 용접한 최종 솔리드.
  대안: 시안에서는 별도 shell을 함께 배치하고 필요한 부위만 수작업 trim/접합. 전체 자동 용접 개발은 보류 가능.
B02 G7/G8 재귀 형상 + 전체 게이트 구성
  이미 완료: 각 기둥과 기존 전체 gate는 별도로 확보.

B03 역할별 분기 + 연속 조직
  이미 완료: branching grammar와 Tissue 각각 실제 형상 확인.

  대안: 저장된 branch/role 결과에서 적용 영역을 수동 선택하고 기존 조직 기능 사용.

3. 필요한 작업과 자동 기능 부재
C01 서로 다른 연구 엔진을 하나로 잇는 최종 설계 조합 경로
  모든 기술을 단일 ALICE parameter interface로 조합·재개하는 범용 runner는 없음.
  대안: 고정한 입력·설정과 기존 출력으로 대안별 별도 recipe/scene를 구성.
  개발 판단: 지금 범용 엔진 개발 불필요
C02 선택 기둥·상인방·조직의 최종 접합
  모든 재귀 부품과 shell을 임의 gate에 자동 맞춤·용접하는 기능은 없음.
  대안: 기존 단면 게이트를 베이스로 사용하거나 DCC에서 단면 맞춤·trim·Boolean.
  개발 판단: 시안 선택 뒤 필요한 접합만 처리
C03 ALICE 의미/매개변수의 정확한 후속 제어 연결
  현재 prototype의 nearest-centroid role 전달을 모든 topology 변화의 정확한 semantic lineage로 확장한 기능은 없음.
  대안: 이번 2–3개 입력은 역할을 명시적으로 지정하고 범위를 고정. 기존 lineage 지원 연산을 우선 사용.
  개발 판단: 시안에는 수동 지정 가능; 제품화 시 재검토
C04 선택된 최종 조합의 형상·교환 확인
  모든 연구 가지와 Tissue 조합에 공통으로 적용한 최종 전체 검증/수리 완료본은 아직 없음.
  대안: 기존 검사·export 도구와 DCC 국소 수리 사용. 발표용과 제작용 검증 범위를 구분.
  개발 판단: 최종 선택안만 필요한 범위로 검증

이미 결합된 것을 다시 미결합으로 보지 않기:
