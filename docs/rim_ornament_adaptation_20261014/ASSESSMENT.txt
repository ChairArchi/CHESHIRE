CHESHIRE — 테두리 방향 적응안 시각화 / 2026-10-14

사용자 지시
앞선 두 프로토타입 이후 기술적으로 가능한 방향을 최대한 시각화하도록 위임받았다.
형태 언어 선택 질문에 답변을 다시 요구하지 않고 세 방향을 실제 메시로 만들었다.

상태와 결정
13장의 신규 실제 렌더와 기존 원본3장을 이용해 네 시점의 비교를 완료하였다.
세 후보 모두 현재 기둥에 채택하지 않는다. 활성 설계 기준은 원본 G7 그대로다.
Mandelbulb의 실제 미세 조직과 곡선 배치, 잎 성장축 교정은 재사용할 기술로 보존한다.
넓은 잎 프로토타입과 거친 단추를 얹는 복합안은 현재 발전 방향에서 제외한다.

실제 구현
기존 표시 영역의 6개 그룹에서 원본 제어 메시의 실제 연결 경로를 얻었다.
그룹별 실제 정점3개를 가이드로 선택하고, 좌표를 PCHIP로 잇고 실제 법선을
보간하였다. 가이드를 벗어나는 구간은 끝 접선으로 선형 연장하며 거리를 기록하였다.
이는 원본 표면으로의 정확한 투영이나 인증된 골 능선 추적이 아니다.
지지 범위가 작은 그룹3에는 모든 후보의 크기를0.38배로 제한하였다.

MANDEL_RIBBON
기존의 닫힌 3D Mandelbulb 프로토타입을 낮고 길게 펼쳐 가이드를 따라 굽혔다.
고립된 작은 버튼에서 방향성 있는 미세 입체 조직으로 바뀐 점은 확인된다.
그러나 확대에서는 수피·암편 같은 거친 삽입물로 읽히며 매끈한 본체와 형태적
연속성이 부족하다. 이 인상은 재질을 바꾼 결과가 아니라 실제 형상에서 발생한다.
인접한 원래의 컵 모양 끝과 불규칙한 겹침은 여전히 노출된다.

LEAF_FAN
잎의 성장축을 법선 방향에서 테두리 접선 방향으로 돌리고 두께·능선을 법선으로
배치하였다. 이전의 작은 파편보다 잎 군집으로 분명하게 읽힌다.
그러나 넓고 매끈한 잎 면이 생겨 미세 디테일보다 새로운 중간 크기 장식의 추가에
가깝다. 성장축 교정은 유효하지만 이 크기와 프로토타입 자체는 채택하지 않는다.

HYBRID
LEAF_FAN의 실제 윗면 정점 두 곳에 작은 Mandelbulb를 중첩하였다.
실제 잎과 군집의 기하학적 중첩은 확인되지만, 매끈한 잎 위에 거친 단추를 얹은
인상이 남는다. 두 조직이 같은 성장 원리로 이어지는 시각적 연속성을 얻지 못했다.
이 조합을 다음 발전 방향으로 채택하지 않는다.

공통 한계와 다음 기준
확대에서는 원본의 삼각면도 세 후보에 공통으로 뚜렷하다. 독립 장식을 겹치는
것만으로 원래의 각진 테두리와 면 구조가 정리되지 않는다.
다음 기술 과제는 후보 수나 장식 종류의 확대가 아니라, 기존 끝에서 작은 조직이
같은 방향으로 이어지도록 근원 형상을 다루는 것이다. 억지로 평활화하거나 별도
장식으로 덮는 방법을 반복하지 않는 편이 타당하다. 이번 작업에서는 그 후속
형상 변경을 실행하지 않았으며 원본과 모든 후보를 별도 보존하였다.

검증 범위
원본의 generation/control/native 파일 해시를 전후 확인하였다. 원본 본체는
Blender에 한 번만 적재하고 각 후보 렌더 뒤 실제 좌표·삼각형 인덱스를 확인하였다.
24개 정규 영역 부착점 검사는 실제 변환 후 닫힌 삼각형의 내부 ray parity를
통과하였다. 반사 복제의 실제 좌표 잔차는0이다. 이는 국소 중첩과 원본 보존의
검증이며 Boolean 융합·용접·접선 연속성·전체 자기교차 해소를 보장하지 않는다.
양의 면적 검사는 모든 부품에 수행하였으나 국소 방향 뒤집힘이나 렌더 float32의
모든 미세 삼각형 비퇴화를 인증하는 검사는 아니다.
