# CHESHIRE — 접힘 흐름 비교, G3 → G5

후속 근접 시험과 G6의 최신 판단은 [NEAR_VIEW_REPORT](NEAR_VIEW_REPORT.md)에 있다. **RULED G6는 표면 텍스처 우세로 조형 실패 판정, 동일 레시피 중단**이다. 아래는 보존한 초기 FLOW 비교 기록이다.

**FLOW는 부분 개선이다. 큰 사선 접힘과 깊은 골을 유지하면서 이전 G5의 짧게 갈라지는 리브를 줄였지만, 측면 격자와 골 주변의 불규칙한 작은 면은 해결하지 못했다.** 이번 결과를 조형 문제의 완결로 보지 않는다.

실제 SPAN·COUNTER G2에서 두 접근을 같은 설정으로 비교했다. RESERVE는 기존 셀 단위 변형을 줄였고, FLOW는 여기에 큰 접힘에서 위치·방향·크기를 유도한 연속 되접힘을 추가했다. G3 실제 렌더를 보고 FLOW만 G4와 G5로 진행했다. 두 입력은 서로 다른 실제 초기 매스이며, 공통 재료 좌표계를 사용하는 범위의 전이 시험이다.

| 시험 | 얻은 것 | 잃은 것 / 남은 문제 | 판단 |
|---|---|---|---|
| RESERVE G3 | 외곽 잔분기가 일부 줄고 큰 골이 남음 | 넓은 부채 판면이 더 드러남. 새로운 접힘 관계는 약함 | G3에서 중단·보존 |
| FLOW G3–G4 | SPAN 사선 어깨가 더 길게 이어짐. 두 하부 공동과 중앙 수렴을 유지하며 작은 꺾임 띠가 발달 | 측면 가로 선반과 중앙의 넓은 패널은 남음. COUNTER의 개선 폭은 작음 | G4를 다음 설계의 우선 체크포인트로 추천 |
| FLOW G5 | 큰 골이 사라지지 않은 채 작은 면과 띠가 추가됨. 이전 TAG_ONLY G5보다 주 접힘이 덜 분절됨 | 좁은 골 양옆에서 다시 잘게 부서진 표면이 나타남. 가까이서 읽히는 규칙성과 부모·자식 접힘의 위계는 불충분 | 세부 발달의 한계 비교용으로 보존 |

정면의 긴 접힘은 개선됐지만 입체 전체의 해결은 아니다. COUNTER 측면 하부의 중앙 수렴부는 여전히 번잡하다. 더 조용해진 면도 있으며, 이를 곧바로 풍부한 위계의 확보라고 해석하지 않는다. G5로 가면 자동으로 아름답게 정리된다는 가설도 지지하지 않는다.

기존 Task36 subdivision, PCHIP 되접힘, authored-profile 태그, 유한 Mandelbulb 형상장을 재사용했다. 별도의 smoothing은 하지 않았다. 새 FLOW G5는 subdivision 5회·형상장 적용 5회이며, 형상장 내부 escape 반복 18회와는 구분한다. IAAC의 정확한 원본 구현이나 물리적 origami solver를 확보했다는 뜻은 아니다. 이전 TAG_ONLY G5와는 생성 경로와 필드 적용 횟수도 달라 단일 변수의 인과 비교가 아니다.

두 최종 G5는 각각 819,202정점·1,638,400삼각형이다. X/Y 정점·삼각형 집합 반사 대칭 오차는 `<4.25e-15`, 연결체 1개, 경계·비다양체 엣지 0, 폐합·winding·기존 최소 면적 기준을 통과했다. **둘 다 자기교차가 확인됐다.** 교차 총량이나 개선 비율은 측정하지 않았다. 중간 세대는 교차 미검사이며 두께·구조·제작 가능성은 모두 미검증이다.

이 FLOW 비교 차수는 G5에서 멈췄다. 후속 사용자 크리틱에서 원거리보다 근접 디테일의 질서가 핵심 문제로 확인됐고, 향후 주두 일부의 스툴 규모 FDM 출력과 G5–G6 디테일 목표가 추가됐다. 따라서 FLOW G4를 보존하면서 더 이른 G1/G2부터 별도 LATE 분기를 진행한다. 세대 수 자체가 질서를 보장한다고 판단하지 않으며, 자기교차는 탐색 중단 기준으로 삼지 않는다. 기존안·중단안·모든 새 체크포인트는 그대로 남겼다. 게이트에는 아직 적용하지 않았다.
