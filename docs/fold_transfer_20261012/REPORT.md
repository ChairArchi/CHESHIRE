# CHESHIRE — 같은 규칙, 다른 초기 매스

**두 실제 초기 매스에 같은 생성 규칙을 적용하는 데는 성공했다. 그러나 정점 보호만으로 접힘의 아름다움과 세대별 위계가 개선되지는 않았다. 이번 분기는 G4에서 멈추고, 형상장 추가 직전의 RETURN_ONLY 두 안을 보존한다.** 기존 OVERLAP G3를 대체하는 최종안으로 선정하지 않는다.

이 문서는 G4 판단 기록이다. 이후 사용자의 작은 조각·부드러운 인상 가설에 따라 G5를 한 차례 추가 시험했다. **최신 결과는 [G5 비교](G5_REPORT.md)**에 별도로 기록한다.

SPAN은 기존의 두 큰 팽창부와 깊은 골을 가진 실제 G0를 사용했다. COUNTER는 기존 초기 매스 함수에서 서로 다른 높이·방향의 팽창부를 직접 생성했다. 완성된 G3를 변형해서 다른 입력처럼 취급하지 않았다. 두 입력은 같은 chart와 메시 위상을 사용하며, **입력별 접힘 위치·강도·필드 설정의 별도 조정 없이** G4까지 발전시켰다. SPAN의 기존 G1–G3는 재사용하고 COUNTER의 G1–G3는 새로 생성했다.

| G4 비교 | 실제로 구현한 것 | 실제 렌더 판단 |
|---|---|---|
| RETURN_ONLY | 기존 표면을 유지하는 재분할 + 여러 셀을 가로지르는 작은 연속 되접힘 2개. 이전 접힘 band의 중심은 보호 | 세 안 중 큰 골과 어깨가 가장 명료하다. 국소 lip·중첩은 늘었지만 전체 개선은 제한적이고 기존의 거친 셀 조직도 남는다. |
| UNPROTECTED | 같은 RETURN_ONLY에 기존 Mandelbrot 계열 형상장 1회 추가 | 일부 중앙 chevron이 약해지고 넓은 패널이 강해진다. 잔조직 증가가 주요 효과다. |
| PROTECTED | 정확히 같은 형상장 이동에 기존 정점·접힘 태그 보호 적용 | 중앙 spine과 층진 골은 더 남지만, 주변 그물·측면 톱니가 강해진다. 조형적 우위가 명확하지 않다. |

COUNTER도 SPAN과 다른 질량 분포를 유지한다. 이는 특정 완성 형상만 고치는 코드에서 벗어날 가능성을 보여준다. 다만 **같은 높이·각도 chart를 가진 두 기둥에서의 입력 전이**를 확인한 것이다. 임의 메시, 다른 위상, 자유로운 전체 스케일, 게이트 부재로의 일반성은 아직 입증하지 않았다. 새 입력을 받는 작은 인터페이스는 분리했지만 추가 입력 시험은 하지 않았다.

기술적으로는 보호 중심 1,190개가 새 되접힘에서 이동하지 않았고, 후속 형상장에서는 보호 feature 1,816개와 모든 기존 control이 고정됐다. 이것은 점·태그 보존이다. **접힘 각도나 면 전체의 형상 기억을 구현한 것은 아니다.** 기존 점 사이 새 점의 이동이 톱니 굴곡을 만드는 것으로 보이며, 다음 반복을 늘리기보다 이 불균형을 먼저 다뤄야 한다.

선별한 두 RETURN_ONLY G4는 각각 409,600개 삼각형이다. X/Y 반사 정점과 삼각형 집합이 대응하고 최대 오차는 `<4.25e-15`; 연결체 1개, 폐합, boundary/nonmanifold edge 0을 확인했다. **두 안 모두 자기교차가 확인됐다.** 교차 총량은 측정하지 않았으며 두께·구조·제작 가능성은 미검증이다. 나머지 형상장 비교안은 빠른 메시 검사와 렌더까지만 수행했고 자기교차는 미검증이다.

이전 CHESHIRE 연구에서 직접 가져온 핵심은 Task36과 평균화·stencil·normal 성분을 분리하는 제어다. 초기 매스·PCHIP 되접힘과 Mandelbrot 형상장 연결은 최근 IAAC 시험에서 마련한 코드를 재사용했다. 두 출처를 모두 과거에 확보된 완성 기술로 묶어 설명하지 않는다. 기존 연산의 보유가 좋은 조형 조합의 완성을 뜻하지는 않는다. Tissue/frame_bundle은 이번 시험에 사용하지 않았다.

이 G4 검토 시점에서는 ① 기존 지역별 가중치를 이용해 셀 경계를 넘는 방향으로 새 점의 변형을 연결하고, ② 그 규칙을 동일하게 두 입력에 적용하는 것이 타당하다고 판단했다. 이후의 G5 후속 시험과 구분한다. 게이트 시험은 진행하지 않았다.
