CHESHIRE — 현재 방향의 G6 간격·깊이 비교
2026-10-13 / Asia-Seoul

실행

실제 DIRECTIONAL G5에서 CC 한 번을 추가하여 G6를 생성했다.
SPAN / COUNTER 두 입력에 같은 규칙을 적용했다.
보존 root 기준 파장은 .70R에서 .35R로 줄이고, 새 법선 요청 진폭 .8 / 1.6만 비교했다.
신규 상태는 네 개다. 기존 G5 두 개는 실제 부모이며 원본 렌더를 재사용했다.
G 번호는 실제 subdivision 횟수다. 새 topology event와 Mandelbulb 평가는 추가하지 않았다.
반주기 방향장과 진폭은 CHESHIRE 가설이며 참고 프로젝트의 복구된 수치가 아니다.

실제 판독

두 입력에서 기존 큰 날 사이의 홈과 층이 더 분리되고 좁은 틈·턱이 추가됐다.
진폭 .8은 일부 층과 작은 골을 추가하지만 기존 큰 평행 림의 흐름이 우세하다.
진폭 1.6은 홈과 경계 변화가 더 크지만 끝면의 톱니·각진 반복도 강화한다.
부모 골에서 중간·미세 골로 분화하는 연속 위계는 여전히 부족하다.
기존 셀·비늘 조직으로 활성 면 전체를 덮는 회귀는 보이지 않는다.
독립 시각 검토도 기존 원본 6장·신규 원본 12장·보드 6장을 확인하여 같은 판정에 도달했다.
전체 세대 증가나 메시 규모를 fine-detail 완성도로 해석하지 않는다.
시각 변화는 확인했으나 연구 판정은 PARTIAL, 최종 미세 마무리 채택은 보류한다.
후속 작업용 출발점은 현재 계보의 DEPTH_08 G6로 둔다. 과거 승인 형상으로 회귀하지 않는다.

장식이 국소적인 이유

이번에도 G3에서 만든 root/child 이벤트 소속의 실제 후손 면만 직접 지원한다.
주변 기존 SOURCE 면 전체를 활성화하거나 새 장식의 위치를 자동 확산한 시험은 아니다.
선택 부위에서의 작은 접힘과 전체 형상의 디테일 분포는 별도의 과제다.
coupled CC의 인접 영향이 있으므로 비활성 면의 XYZ 불변도 주장하지 않는다.

검증과 이미지

기존 core.save의 유한성·폐합·유향 control edge·단일 연결·고립점·native 최소 면적 검사 통과.
네 상태의 실제 control/native XYZ X/Y 대칭과 유향 control quad 대응 통과.
actual native XYZ 반사 최대 오차는 약 1.40e-13이다.
과거 실험 전체 재생, 새 독립 geometry replay, native triangle 집합 정렬 검증은 수행하지 않았다.
기존 G5 원본 6장과 신규 G6 원본 12장, 비교 보드 6장을 저장했다.
정면·근접 사선·근접 측면의 카메라·재질·조명 조건을 맞췄다.
메시마다 control 1,750,530 vertices / 1,750,528 quads,
native 3,501,058 vertices / 7,002,112 triangles다. 이 수치는 미적 성공 지표가 아니다.

개발 운영 기준과 다음 작업

검증된 외부 기술과 이미 보유한 연산자를 재사용한다. 기본 기술을 다시 하나씩 입증하지 않는다.
새 검사는 CHESHIRE 통합에서 발생한 오류·대칭·원본 대응 확인에 한정한다.
반주기·진폭만 바꿔 G7을 자동 반복하지 않는다.
기존 세분·tapered extrusion·cap 연산의 적용 위치와 순서를 조합하여
주변 본체로 디테일을 확장하고 부위별 크기·깊이 관계를 만드는 데 집중한다.
작은 골을 부모 구조와의 접속부부터 끝까지 사선·측면에서 추적할 수 있는지를 우선 본다.
공개 방법의 활용을 위해 기존 작품의 전체 레시피를 정확하게 복원할 필요는 없다.
